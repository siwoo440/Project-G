# 3D 2일차 비행 조작과 마우스 둘러보기

---
## 구현

- 가속·제동과 Shift 집중 비행을 연결했다. 마우스로 선회하고 조준 높이를 바꾼다. 우클릭을 누르면 비행 방향이 유지되고 카메라만 돌아간다.
- 시험 비행 체적과 하늘섬 충돌을 설정했다. 지형이 시야를 가리면 카메라를 당기고, 가림이 풀리면 원래 거리로 복귀한다.

---
## 검증

- Unity Play Mode 5건 통과. 60Hz 고정 시험의 일반 속도는 8.00, 집중은 4.00 월드 단위/초다. 일반 대비 대각선 속도는 1.00배, 집중 입력을 놓은 뒤 제동 거리는 0.275 월드 단위다.
- 경계 고도, 실제 하늘섬 충돌 오브젝트, 카메라 가림과 우클릭 시점 복귀를 자동 시험했다.
- Windows 시험 빌드에서 전진·상승과 정지 뒤 카메라 추적을 확인하고 1920×1080 화면을 캡처했다.
- 직접 조작감과 다른 PC·해상도는 검증 전이다. 3일차는 화면 중심 조준과 기본·집중 마법탄이다.
