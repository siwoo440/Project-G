# 8일차 : 강화 아이템 명칭과 전투 표시 정리

---
## 완료한 작업

- 기획서의 필드 선택형 강화 명칭을 강화 아이템으로 통일했다. 좌우 두 선택지, 시험 효과와 카드의 공통 상한은 유지한다.
- 보스 공격 예고의 주황색 막대를 삼각형 경고 아이콘으로 교체했다. 공격 예고 시간과 상태는 유지한다.
- 경험치 조각을 결정 형태, 약점을 조준 표시, 보조 드론과 회전 칼날을 구별 가능한 형태로 변경했다. 경험치 획득과 약점·보조 공격 판정은 유지한다.
- 기존 시험 발사기의 예고에도 같은 경고 아이콘을 적용했다.

---
## 확인한 테스트

- Unity 6000.3.21f1 배치 모드: EditMode 136건, PlayMode 17건 통과.
- 변경 전에는 경험치 조각과 보스 안내 이미지의 투명 모서리 시험이 실패했고, 변경 후 전체 시험이 통과했다.
- 실제 화면에서 경고와 약점의 가독성, 탄막과의 겹침은 확인하지 않았다.

---
## 남은 작업

- 강화 아이템 6종의 생성·선택·적용과 안전 구간은 아직 구현하지 않았다.
- 카드와 강화 아이템의 공통 상한, 슬롯 동작과 K 교체 후 표시를 연결하고 검증해야 한다.
- 기획서의 기존 시안 이미지는 명칭 변경 전 자료이므로 새로운 아이템 UI 제작 시 교체한다.
- 실제 플레이 화면과 빌드 검증이 남아 8일차는 진행 중이다.

---
## 다음 작업

- 강화 아이템 2지선다와 선택 처리, 안전 구간과 카드 공통 상한을 순서대로 구현한다.

---
## 전투·UI 이미지 추가 작업

- 단색 또는 코드로 그린 시험 표시의 용도를 조사하고 경험치 조각, 공격 예고, 약점, 드론, 회전 칼날, 광선, 시험 표적과 카드 프레임 이미지를 생성해 연결했다.
- 카드 선택 화면에 생성 프레임을 적용하고 드론·칼날·자석 카드에는 해당 역할의 이미지를 표시한다. 기존 스킬 칸 크기와 세 칸 배치는 유지한다.
- 이미지의 투명 채널과 Unity 자원 연결을 확인한다. 플레이 화면의 표시 크기·가독성·탄막 겹침은 수동 확인이 남아 있다.
- Unity 6000.3.21f1 배치 모드에서 이미지 연결 후 EditMode 145건, PlayMode 17건이 통과했다.
- 이미지 생성 도구, 파일 이름과 실제 요청 문장은 `day-08-art-prompts.md`에 기록한다.

## 강화 아이템 기능 추가 작업

- 강화 아이템 6종의 선택과 효과, 카드와의 공통 상한, 누적 제한 및 무효 후보 제외를 연결했다.
- 필드의 서로 다른 후보에 이동해 접촉하면 하나만 획득한다. 후보가 하나만 남으면 하나를 제시하는 예외는 임시 시험 처리다.
- 선택 중 안전 상태와 적탄 정리, 선택 후 0.5초 시험 안전 유예, 카드 선택 대기 및 재출격 정리를 추가했다.
- 그레이즈 에너지의 소수 충전을 누적하며, 방어막은 1회 방어와 재획득 갱신을 지원한다.
- Unity 6000.3.21f1 배치 모드에서 강화·카드·생존 관련 EditMode 30건과 기존 PlayMode 17건이 통과했다.
- 실제 스테이지에서 아이템을 등장시키는 연결은 9일차에 진행한다. 실제 화면과 밸런스·후보 부족 예외의 정식 규칙은 검증 또는 결정 전이다.
