- 상태: 진행 중 — 자동 테스트 통과, 시각 확인과 설정 UI 검증 대기

## 수행한 작업

- 기본 SampleScene에 실행 시 임시 플레이어와 16:9 전투 카메라를 연결했다. 기존 장면 파일은 수정하지 않았다.
- WASD 8방향 이동, 대각선 정규화, 화면 경계 제한을 구현했다.
- 이동 가능 가로 폭의 4초 횡단과 집중 시 50% 속도를 적용했다.
- 화면 위쪽 자동 사격과 Shift 집중 공격을 연결했다. 일반 2발·0.25초, 집중 1발·0.20초는 초기 시험 기준이다.
- 집중 홀드·토글 규칙과 저장된 집중 방식 읽기를 구현했다. 설정 화면과 키 재설정 화면은 후속 작업이다.
- 임시 도형과 시험용 탄환 이동을 사용한다. 피해·충돌·적은 아직 구현하지 않았다.

---
## 검증 결과

- Unity 6000.3.21f1 비대화형 EditMode 테스트 13건 통과: 4초·8초 이동 계산, 경계, 집중·발사 규칙 및 화면 구성.
- 비대화형 PlayMode 테스트 2건 통과: 가상 키보드 이동·집중·발사와 SampleScene 로딩 시 플레이어 생성.
- 두 테스트 모두 원본과 분리된 프로젝트에서 실행했다. 실제 화면의 외형·가독성과 빌드는 확인하지 않았다.
- 격리된 테스트의 Unity Licensing 연결은 거부됐다. 일반 사용자 환경의 비대화형 실행에서는 연결과 테스트가 성공했다.
