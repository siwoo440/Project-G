# 3D 34일차 | 녹스의 그레이즈 표식과 반격

## 구현

- 출격 준비와 마을의 공방·상점에 녹스를 추가했다. 실제 출격, 장비, 공용 스킬과 결과 화면에서 같은 조종사를 사용한다. 준비와 결과는 기획서 전신 일러스트를 공유한다.
- 스침에 성공한 탄마다 표식을 하나 쌓으며 한 출격에서 최대 10개를 보유한다. 표식이 0이면 Q 발동과 마력 소모를 막고 아이콘을 어둡게 표시한다.
- Q 그림자 반격은 보유한 표식을 모두 소비한다. 표식당 피해 15의 반격탄 한 발을 전방에 쏘며 기본 대기는 8초다.
- R 경계 역전은 에너지 100을 소비해 반경 3m 안의 일반 적탄을 지우고 마물에게 피해 150을 준다. 고도도 거리에 포함한다. 보라색 구형 경계는 전투와 연습 씬에서 편집할 수 있다.
- 정밀 회피 1은 그레이즈 3회마다 표식을 하나 더 지급한다. 반격 전환 1은 Q 반격탄의 관통 대상을 하나 늘린다. Q 마력 25와 반격탄의 각도는 3D 시험값이다.

## 검증

- Unity 6000.3.21f1 PlayMode 79개 통과. 실제 적탄 12회의 스침, 표식 상한 10, Q의 10발 발사와 표식 소모, 표식이 없을 때 마력 보존, R의 반경 안팎 피해·소거와 에너지 차감을 확인했다.
- Windows 자동 실행에서 직접 출격해 표식, 반격과 경계의 실제 렌더, 녹스 결과와 같은 조합 재출격을 확인했다. 사용자 직접 조작, 전체 난이도 밸런스, 두 번째 성장 노드는 후속 작업이다.
