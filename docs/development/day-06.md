# 6일차 : 적과 보스 전투 구현

---
## 완료한 작업

- 일반 적 3종: 좌우 이동하며 1.5초마다 조준탄을 쏘는 체력 50 적, 2초마다 부채탄 3발을 쏘는 체력 60 적, 0.8초 예고 뒤 직선 돌진하는 체력 80 적. 돌진 접촉 피해는 15.
- 중간 보스 체력 600, 직선 3연사와 부채탄을 교대. 최종 보스 체력 1500, 체력 구간별 직선 3연사·원형 확산·교차 탄막 시험 패턴.
- 보스는 공격 예고 뒤 발사하며, 패턴 종료 후 시험용 1초 동안 표시된 약점을 노출. 저격형은 노출된 약점에 시험 피해 50%를 추가.
- 기본·집중탄, 스킬탄과 필살기가 실제 적의 체력을 감소시키며, 한 탄환의 동일 대상 중복 적중을 방지.
- 실제 적 처치 시 등급별 필살기 에너지 +2/+10/+20을 한 번 지급하고, 적별 경험치 6/8/10/30/50을 이벤트로 전달. 레벨업과 경험치 보관은 7일차 범위.
- 기존 시험 장면에서 임시 표적 다음으로 적 3종과 보스 2종을 순차 생성하는 반복 시험을 추가. 이는 9일차의 정식 스테이지 웨이브가 아님.
- 화면 위·좌우로 이탈하는 적탄의 풀 회수와 화면 어느 방향으로든 이탈한 돌진형 적의 퇴장을 추가.
- 적과 보스의 시험 체력과 공격 예고를 화면에 표시.
- 스킬 칸을 직전 확대 전 크기로 복원. 1920×1080 기준 한 칸은 360에서 180픽셀로 변경.
- 플레이어·일반 적·보스·아군탄·적탄과 시험 표적의 표시 크기를 가로·세로 세 배로 확대. 이후 요청에 따라 플레이어 표시 크기만 그 절반으로 조정. 적의 공격 예고 표시도 확대하고 보스가 화면 안에 등장하도록 위치를 조정.
- 플레이어 피격·그레이즈, 적·탄환 충돌 및 약점 판정은 기존 크기로 유지. 표시가 커진 적탄은 화면에 보이는 동안 회수하지 않고 소거할 수 있도록 처리.
- 이미지 생성 기본 제공 도구로 투명 배경 시험용 이미지 9종을 제작·적용: 속사형·저격형, 일반 적 3종, 중간·최종 보스, 아군탄·적탄. F1/F2 선택 시 캐릭터 이미지도 변경. 판정 반경과 그레이즈 규칙은 유지.
- 이미지 제작 프롬프트 요지: 위에서 내려다보는 2D 종스크롤 판타지 슈팅용 단일 피사체, 투명 배경, 작은 크기에서도 구분되는 실루엣, 글자·테두리 없음. 캐릭터는 청록·금색 속사형과 청보라색 저격형, 마물은 종류별 날개 실루엣, 탄환은 청록색 아군탄과 붉은 원형 적탄. 저격형은 과도한 광선을 제거하도록 재생성.

---
## 확인한 테스트

- 이전 전투 크기 변경 후 Unity 6000.3.21f1 비대화형 EditMode 109건, PlayMode 10건 통과. 플레이어 크기 조정 후 관련 EditMode 2건과 PlayMode 1건 통과.
- 적별 체력·보상, 탄막 수와 보스 단계, 예고·약점 노출, 연속 돌진 접촉 피해, 적탄과 돌진 적의 화면 이탈, 탄환·필살기 피해와 처치 보상, 시험 장면의 적 등장·처치, 이미지 자원 및 종류별 연결, 피격 표시 크기 유지, 세 배 표시 크기, 보스 등장 위치, 확대 탄환 화면 경계와 스킬 칸 배치 확인.

---
## 남은 문제와 검증

- 실제 게임 화면에서 확대된 이미지와 기존 판정 범위의 차이, 스킬 UI·예고·약점 표시 가독성, 적탄 회피 경로, 보스 패턴 공정성과 밸런스는 미검증. 소요 시간과 성능, 실행 파일 빌드도 미검증.
- 보스 체력 구간을 큰 피해로 한 번에 넘어가는 것을 제한하지 않음. 페이즈 보호는 기획서의 검토 항목이며 확정 규칙이 아님.
- 캐릭터·적 외형과 탄환 이미지는 초기 시험용이며 확정 세계관 설정이 아님. 일부 이동·탄속·패턴 간격과 약점 노출 시간도 시험값. 경험치 이벤트는 아직 저장·레벨업에 반영되지 않음.
- 시험 장면의 적 순차 반복은 전체 웨이브·스테이지·클리어 흐름이 아니며 9일차에 구성 예정.
