# 21일차 : 접근성 안내와 편집 가능한 전투 UI

---
## 완료한 작업

- 첫 출격에 이동, 집중 공격, 스킬, 그레이즈, 필살기 순서의 시험용 안내를 연결했다. 실제 행동과 현재 키 설정을 반영하며 Backspace로 건너뛸 수 있다. 기존 출격 이력이 있는 이용자는 안내를 생략한다.
- 돌진형 적이 실제로 이동할 방향을 예고하는 경로를 표시하고, 예고가 시작될 때 돌진 방향을 고정한다. 일반 탄환의 발사 전 경고는 추가하지 않았다.
- 타이틀의 배경, 제목, 버튼 및 안내를 시작 씬에 저장하고 실제 버튼 입력과 연결했다. 저장된 한글 글꼴은 Nanum Gothic이며 OFL 원문을 빌드에 포함한다.
- 체력과 에너지의 현재·최대값을 막대로 표시하고, 레벨을 `LV. n`으로 표시하며 옆에 현재 경험치 막대를 배치했다. 체력은 좌측 상단, 경험치는 우측 상단, 에너지는 우측 하단 스킬칸 위의 시안 위치를 사용한다. 색상, 크기, 위치와 이미지는 씬에서 편집할 수 있다.
- 경험치 조각을 편집 가능한 프리팹으로 전환해 이미지와 배율이 생성 및 재사용 시 유지되도록 했다. 기존 낙하, 획득, 재사용을 유지하고 잘못된 프리팹 교체 후 복구와 재출격 시 이전 경험치 혼입을 수정했다.
- 타이틀과 게이지에서 대체된 이전 OnGUI 표시 및 경험치 객체의 런타임 이미지 생성 코드를 제거했다. 아직 전환하지 않은 화면과 동적 객체의 기존 코드는 유지한다.

---
## 확인한 테스트

- Unity 6000.3.21f1 비대화형 배치 모드에서 전체 EditMode 430건, PlayMode 61건이 통과했다.
- 가상 입력을 이용해 타이틀 버튼, 설정 모달, 첫 출격 안내와 재출격·건너뛰기를 확인했다. 안내 단계가 같은 프레임에 연속으로 건너뛰지 않는지 확인했다.
- 게이지 값, 씬 참조, 사용자 편집값, 1080p·540p의 계산된 배치와 경험치 프리팹 재사용·재출격 복구를 자동 시험했다.
- 타이틀 화면의 캔버스와 버튼 비활성, 배경 자르기 복원, 파괴된 HUD 카메라 처리 경로를 자동 시험했다.
- 사용자 화면을 전환하지 않는 격리 GPU 실행에서 1080p 타이틀·설정·준비·튜토리얼·전투, 540p HUD와 16:10·4:3 화면 여백을 확인했다. README에는 시험용 체력·에너지·경험치 및 적 피격을 적용한 실제 게임 화면 원본을 반영했다.

---
## 남은 작업과 미정 사항

- 실제 사람이 조작하는 플레이의 가독성과 조작감, 540p 튜토리얼의 GPU 화면은 확인하지 않았다.
- 첫 전체 PlayMode 실행 중 Escape 일시정지 시험이 한 번 실패했지만 단독, 일부 순서 조합, 전체 재실행에서 통과해 원인은 확인하지 못했다.
- 타이틀은 표준 EventSystem이 아닌 기존 입력 경로를 사용한다. 자동 UI 내비게이션, 호버·누름 효과, 겹친 UI의 표준 레이캐스트 우선순위는 지원하지 않는다.
- 캐릭터 선택·출격 준비·설정·카드·스킬 HUD와 적·탄환 등은 아직 기존 런타임 표시 또는 생성 방식을 사용한다. 씬 오브젝트와 프리팹 전환은 계속 필요하다.
- 초보자 안내의 순서와 화면 배치, 적 돌진 경로 표시 및 모든 새 게이지의 세부 수치는 시험 중이며 실제 플레이로 조정해야 한다.
