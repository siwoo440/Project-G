# 3D 62일차: 캐릭터별 빗자루 프리셋

---
## 구현

- 캐릭터별 최대 다섯 개의 이름 있는 프리셋에 여덟 개별 부품, 두 제작 마법 구성·개별 저장 사본과 유지 우선순위를 저장한다. 현재 장착 자동 저장과 이름 있는 프리셋 수동 저장을 구분하고 복제·이름 변경·기록 삭제를 지원한다.
- 프리셋 적용 전 현재 캐릭터, 부품 소유·부위·중복·다른 캐릭터 장착, 정확한 마법 사본·연구·지원 여부와 새 부품의 세트·조건부 효과가 반영된 공격력 한도를 함께 검사한다. 검증에 실패하면 어떤 부품이나 마법도 적용하지 않고 이유를 표시한다.
- 마법 편성 저장을 버전 5로 확장해 같은 구성의 서로 다른 도감 사본을 구별한다. 구형 저장은 읽기만으로 바꾸지 않는다. 장착이나 프리셋이 참조하는 사본의 삭제를 차단한다.
- 출격 준비의 빗자루 조립에 프리셋 목록·이름 입력·저장·적용·복제·이름 변경·삭제, 적용 가능 필터와 전체 능력치 비교를 추가했다. 전체 적용 뒤 조립 목록과 미리보기를 현재 장착으로 갱신한다.
- 기본 부품 여덟 개는 실제 장착을 바꾸기 전에 3D 미리보기로 보여 준다. 취소하면 기존 외형과 장착을 유지하고, 확정 시 모든 부품을 검증해 적용한다. 기본 부품이 없거나 다른 캐릭터가 장착 중이면 이유를 표시한다.

---
## 검증

- Unity 6000.3.21f1 배치 PlayMode 192개가 검증 사본과 `D:\Project-G`에서 각각 통과했다. 실패·건너뜀은 0개다.
- 캐릭터별 다섯 개 상한, 복제본 독립성, 이름 변경·삭제·재실행 복원 및 손상·미래 버전 저장의 덮어쓰기 차단을 확인했다.
- 실제 프리셋 적용과 재진입, 다른 캐릭터 장착·부품 누락·마법 사본 누락·마법 공격력 부족 시 전체 취소, 마법 사본별 참조와 삭제 보호를 시험했다. 한도 부족은 시험용 임시 불이익을 적용하고 원복해 재현했다.
- 실제 출격 준비 UI의 저장·복제·이름 변경·삭제·적용, 적용 가능 필터, 능력치 비교와 조립 목록 갱신을 시험했다. 기본 부품 8개의 외형 미리보기·취소·확정과 타 캐릭터 장착 충돌을 확인했다.
- 글자 크기·버튼 간격을 조정하고 1024×576과 1920×1080의 화면 밖 렌더를 확인했다. [1024×576](../screenshots/3d-day-62-presets-1024.png) · [1920×1080](../screenshots/3d-day-62-presets-1920.png)

## 남은 작업

- 60일차의 화염 궤적·폭발, 별빛 장식·매의 명중 피해 등 남은 빗자루 특수 발동과 충격 저항·안정성의 실제 소비처는 미완료다. 냉기·번개·중력 전용 제작 마법과 공용 대시는 아직 없다.
- 63일차의 부품 도감 이미지 80종과 정식 부품 모델은 미제작이다. 56일차의 구성 아이콘·검색, 아군 연출 강도, 확장 연습 표적·경계와 실측도 미완료다.
- 프리셋의 부품·마법 저장 도중 운영체제 강제 종료, 실제 모니터·다른 PC에서의 수동 가독성 검증과 Steam 실연동은 실행하지 않았다. 검증 실패 시 전체 취소와 저장 재진입은 자동 시험했다.
