# 3D 28일차 아리아·리안 Windows MVP 검증

---
## 두 캐릭터의 출격

Unity 6000.3.21f1 Play Mode 71개를 통과했다. 독립 Windows 1920×1080 빌드에서 두 캐릭터에 질풍의 몸체와 좌측 파이어 볼트를 편성한 뒤 출격했다. 가상 키보드·마우스로 이동, 좌측 카드 사용, 레벨업 카드 선택을 확인했다. 적 처치 피해를 주입하고 조각을 회수할 수 있는 위치를 재현해 실제 경험치와 레벨업 경로를 확인했다. 중간 보스와 최종 보스의 체력 경계는 실제 피해 처리로 재현했다.

아리아는 최종 보스를 격파해 숙련도 20·천공 결정 6개, 리안은 최종 보스 3페이즈에서 피격 실패로 숙련도 10·천공 결정 3개를 받았다. 재출격 시 두 캐릭터 모두 레벨 1·체력 100과 장비·마법을 확인했다. [아리아 보스전](../screenshots/3d-day-28-aria-boss.png) · [아리아 클리어 결과](../screenshots/3d-day-28-aria-result.png) · [리안 보스전](../screenshots/3d-day-28-rian-boss.png) · [리안 실패 결과](../screenshots/3d-day-28-rian-result.png)

같은 버전의 별도 Windows 검증 빌드에서 리안의 첫 웨이브 기록을 남긴 직후 프로세스를 강제 종료했다. 첫 재실행의 실패 복구 지급과 두 번째 재실행에서 보유량이 유지되는지 확인했다. [중단 출격 복구](../screenshots/3d-day-28-recovery.png)

## 1080p 보스 전투 계측

Windows PC의 AMD Ryzen 7 9800X3D, NVIDIA GeForce RTX 5070 Ti에서 1920×1080 창을 격리 데스크톱으로 실행했다. 수직 동기화와 프레임 제한을 끄고, 최종 보스 세 페이즈를 정상 1배속으로 약 10.5초씩 측정했다. 프레임 시간은 게임 루프의 실시간 프레임 간격이다. 아군 탄의 최대치는 30프레임마다 표본을 뽑았다.

| 조종사 | 프레임 수 | 중앙값 | 95백분위 | 활성 적탄 최고 | 활성 아군 탄 표본 최고 |
|---|---:|---:|---:|---:|---:|
| 아리아 | 14,776 | 0.62ms | 0.92ms | 48 / 풀 128 | 7 |
| 리안 | 14,880 | 0.62ms | 0.88ms | 48 / 풀 128 | 5 |

사람이 직접 조작한 완주와 회피 난이도, 실제 디스플레이의 프레젠트 시간, 다른 PC의 프레임 성능은 미검증이다. 29일차에는 착륙장, 광장, 다리, 출격소를 갖춘 3D 마을을 연결한다.
