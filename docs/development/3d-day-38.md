# 3D 38일차 | 비행 모형과 탄막 가독성

---
## 구현

- 기획서의 일곱 전신 일러스트에서 의상과 장비를 참고해 저폴리곤 비행 모형을 제작했다. 루미의 보라색 모자, 리안의 밝은 깃과 긴 총신, 세라의 큰 검처럼 뒤에서 구별되는 요소를 사용했다.
- 실전·훈련 씬의 `AriaPilot/PilotModels`에서 모델을 열어 편집한다. 실제 이동 속도로 좌우 기울기·상하 자세를 만들고 옷자락을 움직인다. 결과 화면은 사용한 조종사의 전신 일러스트를 표시한다.
- 조준형에는 중앙 가시, 확산형에는 넓은 날개 깃, 돌진형에는 긴 뿔과 꼬리를 배치했다. 기존 날갯짓과 이탈 움직임에 붙인 렌더링 전용 요소다.
- 아군 기본탄은 가는 하늘색 바늘, 집중탄은 더 길고 밝은 창으로 보인다. 적탄은 조준 구체, 부채꼴 각판, 고리 보석, 나선 결정으로 모양과 색을 함께 바꿨다. 재사용 풀은 현재 패턴의 공유 메시·재질을 적용하고 기존 피격 반경을 사용한다.
- 정식 항로의 먼 섬과 바다에 맞게 안개 거리를 조정했다. 마물 실루엣과 탄막의 실기 가독성은 후속 밸런스 검증에서 점검한다.

---
## 검증

- Unity 6000.3.21f1 PlayMode 테스트 83개 통과. 선택한 조종사 모델만 표시되는 것, 실제 이동에 따른 비행 자세, 적탄 재사용 때 올바른 형태가 적용되는 것을 확인했다.
- Windows 자동 입력 1920×1080과 1024×576에서 일곱 조종사가 모두 조준점 좌하단에 보이는지 확인했다. 두 해상도에서 일반 마물 세 유형과 적탄 네 패턴 24발을 실제 렌더링했다.
- 모형은 3D 시제품이다. 최종 캐릭터 리깅과 표정, 실제 조작 중 고밀도 탄막 가독성은 검증 범위에 남아 있다.
