## 기준 시험과 미실행 항목

깨끗한 `9dcced5` 복제본에서 Unity `6000.3.21f1` 배치 PlayMode 90개가 통과했다. 실패와 건너뛴 시험은 각각 0개다. 구성 ID 복원, 제작 편집기 저장·시전과 다음 출격 편성, 좌우 시험 덱의 독립 순환, 파일 저장소의 중단 출격 1회 복구, 일곱 조종사의 실제 씬 전투·결과·재출격을 포함한다. 결과 파일은 격리 시험 폴더의 `day47-playmode-retry.xml`이다.

첫 격리 실행은 라이선스 초기화에서 멈춰 해당 Unity 프로세스를 종료했고, 라이선스 서비스에 접근 가능한 환경에서 재실행해 통과했다. 이 시험은 강제 종료된 Windows 플레이어의 재실행 시험을 대체하지 않는다. 46일차의 Windows 강제 종료 복구와 재출격 결과는 당시 기록이며 이번에는 Windows 빌드나 수동 플레이를 다시 실행하지 않았다.

Steam 실연동, 다른 PC의 수동 플레이, 정식 미술·음향 제작과 실제 마법 밸런스 측정은 미완료다.
