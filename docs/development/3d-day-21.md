# 3D 21일차 제작 마법의 조합 규칙

---
## 고정 구성과 저장 ID

속성·탄환 형태·발사 배열·이동 궤적·발사 방식·생성 위치·조준 방식·특수 효과·발동 조건의 고정 비용을 등록했다. 9개 분류에는 101개 선택 항목이 있다. 기획서 15.15의 마법 15종과 침탄 유도 시험 조합에 같은 규칙을 적용했다. 파이어 볼트 20, 수압 파동 23, 홀리 샤워 24, 다크 오비트 40의 비용을 검증했다.

`spell-v1` 구성 ID를 다시 읽을 때 선택지·효과·생성 수를 검증한다. 효과 선택 순서가 달라도 동일한 ID가 생성된다. 유도 조준은 궤적 비용에 포함하고, 분열 자탄 위치나 나선의 기본 순차 발사에 중복 비용을 부과하지 않는다. 두 슬롯에 같은 주문을 편성하면 비용은 두 번 합산한다.

## 공통 검증

| 항목 | 적용 시험값 |
|---|---|
| 최초 생성 / 시전당 누적 | 24 / 96 |
| 초당 생성 / 동시 활성 | 40 / 128 |
| 모탄당 분열 | 최대 3발, 1단계 |
| 추가 특수 효과 | 최대 2종, 동일 효과 중복 차단 |

광선의 공전·분열, 고정 결계의 유도, 설치탄의 회귀, 적탄 흡수와 반사·상쇄의 중복 조합을 차단한다. 화염·물·풀의 순환 상성과 빛·어둠의 상호 약점을 별도 배율로 제공한다. 직선, 평면 부채꼴, 3D 원뿔의 초기 방향과 유도의 시간당 회전을 계산한다.

---
## 검증

Unity 6000.3.21f1 Play Mode 65개 통과. 제작 규칙 18개에서 카드 15종과 유도 시험탄의 편성 비용, ID 복원, 생성 수 경계, 상성, 3D 방향과 궤적을 확인했다. 제작 화면, 실제 표적 발사, 제작 마법 저장·편성은 22일차 범위다.
