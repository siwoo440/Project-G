# 3D 48일차: 제작 마법 2슬롯과 비행 자세

---
## 구현

- 최초 편성은 파이어 볼트와 가시 산탄이다. 저장한 마법을 최대 두 칸에 편성하고 빈 칸과 동일 구성 중복을 허용한다.
- 실제 출격과 재출격마다 편성한 두 칸을 좌우에 무작위 배정하며, 출격 중 편성 변경은 다음 출격에 적용한다. 빈 칸은 표시하거나 발사하지 않는다. 독립 비행 시험 씬의 기존 시험 덱은 유지한다.
- 이전 저장의 유효한 구성 ID와 편성을 읽으며, 양쪽이 시험 덱이었던 기존 저장은 기본 마법으로 시작한다. 새 형식의 명시적인 빈 칸은 그대로 복원하고, 읽는 과정에서 기존 저장을 덮어쓰지 않는다.
- 수압 파동은 세 발이 같은 대상에 시전당 한 번만 피해를 주며 일반 적에게 2m 넉백을 적용한다. 장애물이 있는 방향은 이동을 제한한다. 수평 60도와 수직 20도로 확산한다.
- 정화 결계는 시전 위치에 4초간 유지되고 허용된 적탄만 최대 16발 상쇄한다. 종료 후 12초가 지나야 같은 구성을 다시 시전할 수 있다. 연습 결계는 실전 적탄을 처리하지 않는다.
- 이동 속도에 따라 조종사와 빗자루 외형이 함께 좌우로 기울고 상승·하강 자세를 취한다. 물리체와 마법 발사 지점은 회전시키지 않는다.
- 별도 요청한 UI 선명도와 일곱 캐릭터 초상화 개선을 함께 반영했다. 자세한 변경과 시각 검증 범위는 [UI 후속 기록](ui-clarity-followup.md)을 따른다.

---
## 검증

- Unity 6000.3.21f1 배치 PlayMode 103개 통과, 실패·건너뜀 0개. 기존 전투·저장·정산·재출격과 UI 회귀를 포함한다.
- 기본·빈 칸·중복 편성, 출격별 좌우 배정, 마력 부족 시 소비와 교체 없음, 이전 저장과 새 빈 편성 복원을 확인했다. 중복 구성의 기존 공유 쿨타임도 확인했다.
- 수압 파동의 세 발이 모두 같은 표적에 닿는 대조 시험에서 공유 적중 제한 적용 시 피해 36, 제한 해제 시 피해 108을 확인했다. 일반 마물의 2m 넉백과 수평·수직 발사 각도를 시험했다.
- 정화 결계의 16발 한도, 상쇄 불허 탄 보존, 고정 위치, 유지 종료와 재사용 시간, 연습과 실전 적탄 격리를 시험했다.
- 비행 시험 및 외곽 항로에서 조종사·빗자루와 장착 부품의 기울기, 발사 위치와 조준 방향 보존을 시험했다.

## 미검증과 다음 작업

- 실제 Windows 플레이어에서 결계 선의 가독성과 비행 기울기 체감, 다른 PC와 수동 조작은 확인하지 않았다. UI 렌더 텍스처 캡처는 실제 화면 오버레이의 대체 검증이 아니다.
- 정예 적 전용 저항과 개별 보스 핵심 특수탄의 상쇄 불허 설정은 현재 적 종류·공격 분류에 연결된 데이터가 없어 실전 검증하지 않았다. 일반 적 및 명시적으로 상쇄를 금지한 시험 탄은 확인했다.
- 49일차에는 같은 구성 ID의 전투 강화 공유, +3 상한과 카드 비용·제약 표시, 저장 호환과 재출격 초기화를 구현한다. 공유 쿨타임의 기본 동작은 이번 시험에서 확인했으나 49일차 전체 완료를 의미하지 않는다.
- Steam 실연동, 다른 PC 검증, 정식 미술·사운드 제작은 별도 후속 작업이다.
