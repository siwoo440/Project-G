# 3D 43일차 | 탐험 경로와 임시 상점

---
## 시제품 동선

- 출격 준비의 **탐험** 또는 **F6**에서 선택한 조종사로 시작한다. 지도는 항구·갈림길·교전 또는 보급·임시 상점·최종 전투의 다섯 위치를 표시한다.
- 교전에서는 일반 마물 두 웨이브를 처리하고 보급표 2장과 자동탄 피해 +20%를 얻는다. 우회 보급은 교전을 건너뛰고 보급표 1장을 얻는다.
- 임시 상점에서 보급표 1장으로 자동탄 피해 +20%를 한 번 추가할 수 있다. 실제 기본·집중 자동탄에 반영한다. 최종 전투에는 기존 최종 보스 3페이즈를 사용한다.
- 지도 지점과 구매 시 조종사, 경로, 보급표, 강화 상태를 하나의 체크포인트에 기록한다. 닫은 뒤 또는 실행을 다시 시작한 뒤 F6에서 이어간다. 전투 중 종료했다면 해당 전투 입구부터 시작한다.
- 실패·최종 완료·확정 포기 시 임시 진행만 초기화한다. 본편 영구 재화·숙련도·이어하기는 보존한다.
- 지도는 `SortieBriefing/ExpeditionMap`, 전투 배치는 `OuterIslandsStage/EnemyEncounter`에서 편집한다. 준비의 보조 모드 네 버튼은 스탠딩을 피하도록 오른쪽 정보 패널에 수평 정렬했다.

---
## 검증

- Unity PlayMode 89개 통과. 유효한 두 분기, 임시 상점의 중복 구매 차단, 저장을 다시 읽은 조종사·강화, 별도 전투와 실패를 확인했다.
- Windows 1920×1080과 1024×768 자동 검증에서 F6, 두 경로, 강화 배율, 메모리 상태를 비운 뒤 저장 복원, 통제된 피격·격파와 본편 재화 보존을 확인했다.
