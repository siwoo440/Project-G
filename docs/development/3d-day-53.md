# 3D 53일차: 광선·흡수·낙인과 속성

---
## 구현

- 루미너스 레이는 실제 좌우 버튼을 유지하는 동안 조준선의 첫 대상에게 0.5초마다 피해를 주며, 지형과 첫 표적을 관통하거나 적탄을 지우지 않는다. 시작 마력과 유지 마력을 각각 소비하고 자연 회복은 유지한다. 입력 해제·마력 부족·최대 시간 종료 후 재사용 대기를 시작한다. 제작 연습에서는 최대 시간까지 자동 유지한다.
- 다크 오비트는 네 위성이 공전하며 흡수가 허용된 적탄만 시전당 합계 10발까지 회수하고 발당 마력 1을 돌려준다. 상쇄와 흡수 허용을 서로 다른 적탄 속성으로 관리한다. 개별 흡수 여부가 정해지지 않은 보스탄은 흡수 불가로 둔다.
- 그림자 낙인은 직격 후 저주를 적용한다. 저주는 0.5초마다 최대 6회 피해를 주고 만료 전에는 중복되거나 갱신되지 않는다.
- 기획서의 초과 생성 즉시 차단 규칙에 맞춰 순차 발사와 분열을 수정했다. 한도에 들어가는 발사만 수행하며 차단한 탄환을 나중에 발사하지 않는다. 52일차 기록의 이전 지연 설명도 바로잡았다.
- 확정된 15종만 실제 시전하며 미확정 범용 조합은 미지원으로 유지한다. 연구·해금 전까지 추가 11종은 시험용으로 접근할 수 있다.

---
## 검증

- Unity 6000.3.21f1 배치 PlayMode 130개 통과, 실패·건너뜀 0개. 저장·전투·정산·재출격 회귀를 포함한다.
- 광선의 6회 총 132 피해, 첫 대상만 타격, 조준 변경과 지형 차단을 확인했다. 실전 카드의 가상 버튼 입력으로 기본 회복을 제외한 3초 소비 34, 입력 해제·마력 고갈 시 종료와 종료 후 쿨타임을 시험했다. 유지 중 기본 마력 회복도 확인했다.
- 위성 4개와 허용탄 10발 흡수, 불허탄 및 11번째 탄 보존, 실제 마력 10 회복과 유지 종료를 확인했다. 상쇄 가능 여부와 흡수 가능 여부가 서로 다른 탄도 시험했다.
- 그림자 낙인의 직격 14와 저주 6회 총 62 피해 및 만료 전 중복 불가를 확인했다. 5×5 속성 배율 25개와 미지정 방어 속성 5개를 대조했다.
- 초당 생성 한도에서 가능한 자탄만 생성하고 초과 자탄과 순차 탄환을 지연 생성하지 않는 경계를 시험했다.

- 54일차에는 동일 조종사의 숙련도와 연구 과제, 선행 노드, 계정 공용 연구 자격·해금 저장을 연결한다.
