# 3D 27일차 첫 비행 안내와 화면비

---
## 첫 비행 훈련

`FlightSortieBriefing`에서 첫 비행 안내 버튼 또는 F1로 선택한 조종사의 연습을 연다. 기존 `FlightPrototype`에서 이동 2m, 집중 0.4초, 실제 자동탄 적중, 실제 적탄 그레이즈, 고유·공용 스킬 사용을 순서대로 확인한다. 조작 키를 변경하면 안내 문구에도 반영된다.

Enter로 언제든 출격 준비에 복귀하고, Tab으로 포인터를 열어 안내 버튼을 클릭할 수 있다. 완료하면 포인터가 자동으로 표시된다. 훈련은 정식 출격 참여나 영구 보상으로 기록하지 않는다. 안내 패널은 `FlightPrototype/CombatHUD/FirstSortieGuide`에서 편집한다.

## 화면과 검증

메인·출격 준비·결과 화면을 전투 HUD와 같은 가로 너비 기준으로 조정했다. 설정 목록에 1280×800과 1024×768을 추가했다.

Unity 6000.3.21f1 Play Mode 71개에서 선택형 입문, 실제 이동·집중·적중·그레이즈, 건너뛰기 후 준비 복귀, 실전 HUD의 안내 미표시를 확인했다. Windows에서는 1024×576에서 F1과 재설정한 H를 포함한 다섯 단계 및 리안의 복귀를 검증했다. [첫 비행 안내](../screenshots/3d-day-27-guide-1024.png)

Windows 1024×576, 1280×800, 1024×768에서 출격 버튼·스탠딩, 전투 타이머·체력·마력·레이더·스킬·마법 카드의 화면 범위를 확인했다. [소형 16:9](../screenshots/3d-day-27-hud-1024.png) · [16:10](../screenshots/3d-day-27-hud-16x10.png) · [4:3](../screenshots/3d-day-27-hud-4x3.png) · [4:3 준비 화면](../screenshots/3d-day-27-briefing-4x3.png)

다른 PC에서의 성능과 사람이 직접 플레이한 완주는 28일차 검증에 남아 있다.
