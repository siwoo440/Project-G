# 22일차 : 메뉴·전투 씬과 오른쪽 정보 패널

---
## 완료한 작업

- 기존 SampleScene을 메뉴 씬으로 보존하고 BattleScene을 빌드 설정에 추가했다. 출격 시 전투 씬을 비동기로 불러오며 실제 카메라·배경·플레이어·스테이지·HUD를 씬의 직렬화된 오브젝트로 연결한다.
- 전투 씬 Hierarchy에서 적·보스 5종과 적탄의 비활성 템플릿을 편집할 수 있게 했다. 실제 등장 객체가 템플릿의 이미지·색상·크기를 사용하며 적의 판정과 탄환 판정은 별도로 유지한다.
- 전투 화면은 16:9 콘텐츠 영역 안에서 왼쪽 75%, 정보 패널은 오른쪽 25%의 시험 배치로 구성했다. 실제 카메라 종횡비와 이동·적 생성·탄환 소거 경계를 연결하고 일반 가로 횡단 4초와 집중 이동 50%를 시험했다.
- 오른쪽 씬 패널에 HP·에너지·LV/XP·그레이즈·캐릭터 정보와 세 스킬 슬롯을 배치했다. 스킬 슬롯은 재지정 키·흰색 쿨타임·에너지 부족 음영을 표시한다.
- 게임 영역을 벗어난 아군 탄환이 화면 밖 대상에 피해를 주지 않도록 하고, 경계 안의 연속 적중과 관통을 유지했다.
- 편집 가능한 사운드 설정 패널과 AudioSource, 다섯 음량의 시험 기본값 및 독립 저장·복원, 실제 성공 이벤트 연결을 추가했다. 최종 음원과 음성은 지정하지 않았다.
- 비동기 로딩의 중복 요청, 시작 저장 실패, 늦게 완료된 씬 정리 및 재출격 경계를 처리했다. 기존 진행 저장과 정산 기록 형식은 유지한다.

## 확인한 테스트

- Unity 6000.3.21f1의 격리 배치에서 전체 EditMode 506건, PlayMode 77건이 통과했다.
- 실제 씬 로딩과 재출격, 시작 저장 실패, 시간 정지 중 재시도, 기존 호스트 파괴 시 씬 정리, 적 템플릿 편집값의 실제 등장 반영을 시험했다.
- 1080p와 540p의 씬 배치, 카메라 경계·횡단 속도·모달 입력·게이지 유지·스킬 표시를 자동 시험했다.
- 사운드 설정의 시험 기본값·저장/복원·오류, 메뉴와 전투의 설정 입력 및 AudioListener 중복 방지를 자동 시험했다.
- 사용자 화면을 전환하지 않는 격리 GPU 실행에서 아리아·리안의 1080p·540p 전투, 16:10·4:3 화면, 오른쪽 패널과 사운드·카드 모달의 표시를 확인했다. 스킬 세 칸의 정사각형 비율, 실제 적탄과 모달 안내 겹침 방지도 확인했다. README에는 시험 수치를 적용한 원본 화면을 반영했다.

## 남은 작업과 미정 사항

- 최종 음원과 음성 파일은 없으며, 실제 BGM·효과음 청취와 믹스 품질은 확인하지 않았다. 음량 기본값은 기획서의 시험값이다. 격리 플레이어 종료 시 ComputeBuffer 정리 경고가 기록됐으며 사용자 수동 플레이는 하지 않았다.
- 75:25 비율은 시험 배치다. 게임 조작감과 일반 이동 4초/집중 이동 8초의 새 영역 적용은 실제 플레이를 통해 검증해야 한다.
- 실제 출격 기록 저장 직후 강제 종료될 때는 기존 저장 형식에서 전투 진입 전후를 구분하지 못한다. 강제 종료 출격의 아리아 과제 증거 복구는 기존 미구현 사항이다.
- 아군 탄환·강화 아이템과 일부 메뉴·모달은 아직 코드 생성 또는 OnGUI 방식이다. 사용자가 씬과 Hierarchy에서 편집할 수 있도록 추가 전환이 필요하다.
- 플레이어와 적탄 이미지는 사용자의 원본 PNG와 메타데이터를 보존한 별도 Sprite 자산을 사용한다. 적 종류 간 템플릿 참조를 서로 바꾸면 자동으로 종류를 구분하지 못한다.
