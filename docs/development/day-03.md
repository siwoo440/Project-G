## 수행한 작업

- 적탄 생성·이동과 화면 이탈 시 회수, 객체 재사용을 구현했다. 시험용 풀 상한은 256개다.
- 적탄의 생성 위치를 미리 표시하고 플레이어가 생성 지점에 가까우면 해당 발사를 생략한다. 발사 간격 1.25초, 속도 3, 적탄 반경 0.06은 시험값이다.
- 플레이어 피격 반경 0.12, 그레이즈 반경 0.40과 탄환 반경을 함께 적용한다. 프레임 사이의 상대 이동을 연속 판정한다.
- 피격 판정을 우선하고 적탄당 그레이즈를 한 번만 기록한다. 풀 재사용 시 그레이즈 상태를 초기화한다.
- 시험 체력 100, 일반 적탄 피해 10, 피격 후 무적 1초 및 체력 0 시 이동·발사 중지를 구현했다. 무적 중 몸에 닿은 탄환도 회수하는 것은 시험용 처리다.
- 체력·그레이즈와 출격 실패 상태를 임시로 표시하고, 일반 OFF·집중 ON을 기본으로 피격 중심 표시를 추가했다.
- 그레이즈는 횟수만 기록한다. 필살기 에너지 충전은 4일차 작업이다.

---
## 검증 결과

- Unity 6000.3.21f1의 분리된 시험 프로젝트에서 EditMode 35건, PlayMode 5건 통과.
- 판정 경계·상대 이동 통과·무적 1초·체력 0·정지 중 판정, 탄환별 그레이즈와 풀 재사용을 검증했다.
- PlayMode에서 장면 로딩, 키 입력, 시험 적탄 예고·생성, 피격·그레이즈·중복 피해 방지를 검증했다.
- 비대화형 실행으로 검증했으며 실제 화면의 외형·가독성, 난이도와 빌드는 확인하지 않았다.
