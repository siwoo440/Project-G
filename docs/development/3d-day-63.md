# 3D 63일차: 빗자루 부품 도감과 이미지

---
## 구현

- 14.10의 10개 세트·80개 부품 이름과 외형 설명을 실제 카탈로그와 대조한 뒤 각 부품의 투명 배경 2D 이미지를 제작했다. 기획서의 해당 이미지 칸에도 개별 그림을 삽입했다.
- 빗자루 조립에서 열 세트와 세트별 여덟 부위를 탐색하고, 선택한 부품의 그림·보유 수·기획 특수 효과 및 세트 2·4·8단계 설명을 볼 수 있다. 아직 연결되지 않은 발동 효과는 기획 표시와 구분해 안내한다.
- Unity가 원본 이미지의 가로세로 비율을 바꾸지 않도록 도감 전용 가져오기 설정을 추가했다. 원본 해상도·투명도와 밉맵을 보존하고 축소 필터와 선명도 보정을 적용한다. 다른 그림으로 이동할 때 이전 도감 텍스처를 해제한다.

---
## 검증

- Unity 6000.3.21f1 배치 PlayMode 194개가 검증 사본과 `D:\Project-G`에서 각각 통과했다. 실패·건너뜀은 0개다.
- 80개 카탈로그 ID마다 실제 PNG가 존재하고 Unity가 원본 가로·세로 크기와 삼중 선형 축소 필터·밉맵을 유지하는지 확인했다. 모든 원본의 가로·세로는 768픽셀 이상이고 모서리 투명도를 확인했다.
- 실제 도감의 열 세트 탐색, 8개 부위, 정확한 그림 연결·원본 비율, 2·4·8세트 설명과 이전 그림 해제 후 재로드를 자동 시험했다.
- 기획서 14.10에서 삽입한 이미지 80개가 각각 해당 이름의 이미지 칸에 들어간 것을 문서 객체 ID로 확인했다. 도감의 1024×576·1920×1080 화면 밖 렌더를 확인했다. [1024×576](../screenshots/3d-day-63-gallery-1024.png) · [1920×1080](../screenshots/3d-day-63-gallery-1920.png)

## 남은 작업

- 63일차는 **부분 완료**다. 새 그림은 2D 도감 리소스이며 실제 부품별 정식 3D 모델이 아니다. 기존 여덟 부착점과 임시 미리보기를 사용하고, 부품별 정식 모델·희귀도별 재질·발광·장식은 제작하지 않았다.
- 희귀도·세트·강화·장착 상태별 조립 부품 필터와 전체 정렬은 미완료다. 프리셋에는 현재 적용 가능 여부 필터가 있다.
- 60일차의 화염 궤적·폭발, 별빛 장식·매의 명중 피해 등 남은 특수 발동과 충격 저항·안정성의 실제 소비처는 미완료다. 냉기·번개·중력 전용 제작 마법과 공용 대시도 아직 없다.
- 기획서 전체 PDF 내보내기가 실패해 80개 이미지 삽입 후 전체 문서의 페이지 나눔과 인쇄 배치는 확인하지 못했다. 실제 모니터·다른 PC 수동 검증, 정식 리소스, Steam 실연동과 이전 일차의 미실행 항목도 남아 있다.
