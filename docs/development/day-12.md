# 12일차 : 강화 아이템 드롭과 스테이지 연결

---
## 완료한 작업

- 일반 적 처치 시 강화 아이템이 확률로 나타나며, 전투를 멈추지 않고 이동해 획득하도록 시험 구현했다. 기존 스테이지의 두 차례 고정 강화 선택을 제거하고 보스 진입 안전 구간은 유지했다.
- 기존 6종과 회복 물약·에너지 결정·회수 자석을 포함한 9종에 I~V 등급별 초기 시험 효과를 적용했다. 카드와 아이템의 피해·발사 간격·추가 관통·고유기 쿨타임 상한을 함께 확인하고, 카드 선택 화면에 실제 누적값과 적용 후 수치를 표시한다.
- 자석은 등급별 범위 또는 전투 화면의 활성 경험치 조각을 즉시 수집하고, 획득 시 실제 변화량을 표시한다. Tab을 누르는 동안 아이템의 누적 효과를 확인할 수 있다.
- 신규 세 아이템은 내장 이미지 생성 도구로 만든 투명 배경 시험 이미지를 사용했다. 기존 전투 이미지와 혼용하며 실제 크기와 가독성은 검증 전이다.
- 드롭은 전투 객체에 속하며 재출격 시 제거한다. 보스 드롭은 기획 미정으로 현재 구현하지 않았다.

---
## 시험값과 미정 사항

- 일반 적 처치당 드롭 10%, I~V 등급 가중치 50·25·15·7·3은 초기 시험값이다. 유효 후보가 없는 등급은 제외하고 나머지 가중치를 재분배한다.
- 획득 반경 0.65 월드 단위와 필드 유지 20초는 미정인 값을 시험하기 위한 임시값이다. 획득 시 무효가 된 아이템은 일단 유지하는 시험 처리다.
- 시간제 보호막과 강화 보호막의 소모 순서는 미정이므로 기존 시간제 보호막을 우선 소모하는 시험 처리다.

---
## 확인한 테스트

- Unity 6000.3.21f1 배치 모드에서 EditMode 251건과 PlayMode 32건이 통과했다. 실제 전투 구성의 일반 적 처치부터 드롭 획득·재출격 초기화도 자동 시험했다.
- 등급별 효과와 상한, 적 처치 드롭 추첨, 경험치 일괄 회수, 보스 전환 안전 상태, 저장된 성장 유지와 재출격 초기화를 자동 시험했다.

---
## 남은 작업

- 실제 화면의 아이템 이미지 크기·탄막과의 겹침·획득 동선과 두 캐릭터의 실제 플레이 밸런스는 검증하지 않았다.
- 유료 해금 상품·카드 후보와 도전 과제 조건은 미정이며 전체 영구 해금 흐름은 아직 검증할 수 없다.
- 실제 프로세스 강제 종료 후 저장 복구는 수행하지 않았다. 보스 드롭 여부와 획득 반경·유지 시간, 보호막 간 소모 순서는 정식 설정으로 확정하지 않았다.

---
## 다음 일차

- 13일차에 전투 측정·재현 준비를 진행하고, 실제 플레이와 렌더링 성능이 필요한 항목은 자동 배치 시험과 구분해 기록한다.
