# 13일차 : 출격 측정과 재현 준비

---
## 완료한 작업

- 출격별 시드를 생성해 카드와 아이템 드롭에 독립적으로 연결했다. 같은 시드와 같은 입력 조건의 추첨을 다시 실행할 수 있다.
- 필살기 발동, 드롭 시도와 생성·획득·만료·출격 종료 폐기, 아이템 종류·등급 및 중간·최종 보스 등장·돌파를 출격 통계에 추가했다.
- 전투·전체 시간, 선택 카드, 적 처치·피격·그레이즈, 현재와 관측 최대 활성 적탄 수를 측정 보고에 연결했다.
- 실제 렌더링 중인 전투의 프레임 표본과 해상도·수직 동기화·FPS 제한·CPU·GPU·메모리·운영체제·Unity 버전을 기록한다. 입력 출처가 확인되지 않으면 실제 사용자 플레이로 단정하지 않는다.
- 출격 도중 화면 설정이 변경되면 이후 성능 표본을 중단하고 변경 전 구간만 보고한다. 그래픽 장치를 사용하지 않거나 표본이 없으면 FPS와 프레임 시간은 미측정으로 표시한다.
- 실제 출격 정산 후 `Application.persistentDataPath/ProjectGMeasurements`에 고유한 텍스트 보고서를 저장한다. 저장 실패 시 보고를 메모리에 보관하고 Tab 재시도를 제공한다. 프로그램이 종료되면 미저장 메모리는 보존되지 않는다.
- 기획서에 14~24일차 MVP 보완 일정과 25~28일차 후속 모드 검토 초안을 추가했다. 미정인 설정과 기획 제안은 확정하지 않았다.

---
## 확인한 테스트

- Unity 6000.3.21f1 비대화형 배치 모드에서 EditMode 285건과 PlayMode 37건이 통과했다.
- 같은 시드의 카드·드롭 재현, 필살기와 드롭 결과, 보스 등장·돌파, 보고서의 마지막 관측 단계와 재출격 초기화, 적탄 최대 관측 수, 정산 후 보고 생성과 저장 실패 재시도를 격리된 시험 데이터로 확인했다.
- 가상 화면 환경에서 설정 변경 전후 표본 혼합 방지와 배치 모드의 렌더링 성능 미측정 처리를 확인했다. 실제 모니터 설정이나 사용자 성장 파일을 바꾸지 않았다.

---
## 남은 작업

- 실제 사람이 플레이한 3~5분 출격, 카드 5~8회·필살기 1~2회와 조작감·탄막 가독성·위험 구역 아이템 회수를 측정하지 않았다.
- 실제 그래픽 장치의 동일 조건 1080p FPS·프레임 시간과 성능 목표 달성 여부는 측정하지 않았다. 배치 모드 결과는 실렌더 성능이 아니다.
- 유료 해금 상품과 도전 과제 조건이 미정이므로 첫 해금까지의 실제 출격 횟수와 전체 영구 해금 흐름은 측정하지 못했다.
- 실제 프로세스 강제 종료 후 복구, 실제 화면의 보고서 표시·저장 경로와 저장 실패 재시도는 확인하지 않았다. FPS 계측에는 수집기 자체의 부하가 포함된다.
- 현재 최대 적탄 수는 프레임마다 관찰한 값이므로 프레임 사이에 생성·회수된 탄환은 최고치에 잡히지 않을 수 있다.
