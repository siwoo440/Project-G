# 11일차 : 출격 보상과 영구 저장 연결

---
## 완료한 작업

- 출격 시작 시 고유 ID와 캐릭터를 저장하고, 결과 화면 진입 전에 출격 결과와 보상을 한 번만 정산하도록 연결했다.
- 초기 시험값으로 참여 숙련도 10·공통 재료 3개, 클리어 추가 숙련도 10·공통 재료 3개를 지급한다. 캐릭터별 누적 숙련도 60마다 해당 전용 재료 1개를 지급한다.
- 결과 화면에 실제 숙련도와 재료 획득량을, 출격 준비 화면에 선택한 캐릭터의 누적 숙련도·전용 재료와 공통 재료를 표시한다.
- 일시정지에서 확인 후 재시도하거나 출격 준비로 복귀하는 경우 참여 실패로 정산하는 시험 처리를 연결했다. 기획서에는 이 두 경로의 정산 방식이 명시되지 않아 추후 검증 대상이다.
- 성장과 출격 기록을 설정과 별도의 파일에 저장한다. 중복 정산, 동시 실행 충돌, 저장 실패와 손상된 파일의 덮어쓰기를 방지하며, 실패 시 전투를 보존하고 저장 재시도를 제공한다.
- 기획서 4.5에 따라 중단된 미정산 출격을 다음 실행에서 실패로 한 번 정산하는 기본 복구를 앞당겨 연결했다. 현재 다른 게임 실행이 파일을 사용 중이면 복구하지 않고 오류를 표시한다.
- 해금의 재료 차감·중복·캐릭터·선행 조건을 검증하는 시험 가능한 저장 구조를 마련했다. 현재 확정된 유료 상품이 없어 실제 해금 목록은 비어 있고, 기존 전용 카드의 첫 노드는 기본 후보로 유지한다.
- 도전 과제는 조건과 보상이 미정임을 표시한다. 임의의 진행률·완료 조건·보상은 추가하지 않았다.

---
## 확인한 테스트

- Unity 6000.3.21f1 배치 모드에서 EditMode 214건과 PlayMode 28건이 통과했다. 실제 사용자 성장 파일과 분리된 저장소를 사용했다.
- 참여·클리어 지급, 캐릭터별 숙련도 경계, 출격 ID 중복, 저장 실패·재시도, 복원, 중단 출격 실패 정산 및 동시 사용 차단을 자동 시험했다.
- 실제 프레임에서 실패 결과와 누적 성장, 재출격, 저장 실패 중 정지와 재시도를 시험했다. 파일 손상·잘못된 UTF-8·저장 크기 제한도 격리 파일 또는 메모리로 시험했다.

---
## 남은 작업

- 유료 해금 상품·후속 카드 ID와 효과, 도전 과제의 세부 조건·보상량은 미정이다. 실제 해금 선택과 카드 후보 반영은 상품이 정해진 뒤 연결해야 한다.
- 중단 출격 복구는 저장된 미정산 상태를 이용한 자동 시험까지 확인했다. 실제 프로세스 강제 종료 후 재실행과 전체 출격 흐름은 아직 검증하지 않았다.
- 실제 게임 화면의 결과·출격 준비 UI 가독성, 조작감과 저장 권한·모니터 환경은 확인하지 않았다. 숙련도·재료 수치와 첫 해금 속도는 플레이 검증 전 시험값이다.
- 저장 내역이 복원 크기 한도에 도달하면 기록을 덮어쓰지 않고 저장을 중단한다. 장기 운용을 위한 안전한 내역 정리 방식은 후속 작업이다.
