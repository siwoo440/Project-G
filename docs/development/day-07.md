# 7일차 : 경험치와 카드 성장 시험 구현

---
## 완료한 작업

- 적 처치 위치에 경험치 조각을 생성하고, 플레이어에게 흡수되면 경험치를 누적한다. 기본 흡수 반경 1.5와 조각 이동 속도는 시험값이다.
- 레벨별 요구 경험치 `10 + 6 × (현재 레벨 − 1)`과 복수 레벨업 대기열을 연결했다.
- 레벨업 시 전투를 즉시 정지하고 서로 다른 카드 3장 중 하나를 선택한 뒤 이전 시간 배율로 복귀한다. 숫자 1·2·3과 마우스를 지원한다.
- 공용 카드 12종과 각 캐릭터의 분기별 첫 카드 4종을 최신 기획 수치에 맞춰 연결했다. 카드 최대 단계, 캐릭터, 장비와 회복 조건을 검사하며 후보가 있는 등급의 가중치 75:20:5를 사용한다.
- K 산탄 선택 시 교체 확인과 취소를 제공하고 기존 스킬 효과 및 남은 대기 시간을 표시한다. K 전용 강화는 현재 구현된 항목이 없다.
- 공격 드론, 회전 칼날과 자석·보호 장치·집속 렌즈를 시험 구현하고 공격력·연사·관통·쿨타임 공통 상한을 적용했다.
- 후보 부족 시 유효한 체력 회복 10과 필살기 에너지 충전 5를 우선 제시한다. 그래도 선택지가 부족하면 서로 다른 최대 체력 증가 1·2·3을 임시 대체 보상으로 사용한다. 보상 수치와 부족 예외는 확정 규칙이 아닌 시험값이다.
- 새 출격 시 카드·경험치·레벨업 대기열을 초기화하고, 선택 중 적과 탄환이 같은 프레임에도 진행하지 않도록 정지 처리를 보강했다.

---
## 확인한 테스트

- Unity 6000.3.21f1 배치 모드: EditMode 134건, PlayMode 17건 통과.
- 적 처치 → 경험치 획득 → 레벨업 → 카드 선택 → 전투 재개 흐름, 복수 레벨업, 후보 필터와 가중치, 카드 효과, K 교체 확인·취소, 키보드·마우스 입력 및 전투 정지를 자동 시험했다.
- 실제 실행 화면, 글꼴·배치·가독성, 플레이 감각, 밸런스와 성능은 확인하지 않았다. 독립 실행 파일 빌드도 확인하지 않았다.

---
## 남은 작업

- 카드 화면과 드론·칼날은 시험용 표시다. 실제 화면에서 카드·HUD·적탄의 겹침과 글꼴을 확인해야 한다. 터치 조작은 구현하지 않았다.
- 경험치 조각 수명, 흡수 반경, 대체 보상 수치와 세 선택지가 부족한 예외는 플레이 검증 및 기획 결정이 필요하다.
- 전용 분기의 후속 노드와 영구 해금은 MVP 이후 범위이며 아직 구현하지 않았다.
- 스테이지 전환 중 선택을 미루는 연결과 3~5분 동안 카드 5~8회 선택 목표의 측정은 정식 스테이지 작업에 남아 있다.
- 자동 시험은 통과했으나 실제 플레이 확인이 남아 7일차는 진행 중으로 기록한다.
