# 4일차 : 스킬과 전투 UI 구현

## 완료한 작업

- 속사형 J 스킬: 3초간 발사 간격 30% 감소, 효과 종료 후 8초 쿨타임 적용.
- 공용 K 스킬: 1초 동안 유효한 1회 방어 보호막 또는 탄환 3발을 발사하는 산탄. 시험 피해량은 발당 12, 쿨타임은 각각 12초와 10초.
- 교체 중 남은 공용 스킬 쿨타임을 유지하는 시험 규칙 적용.
- 필살기 에너지는 최대 100, 그레이즈 +1, 일반 적 +2, 중간 보스 +10, 최종 보스 +20으로 설정. 필살기 사용 시 에너지 100을 소모하고 화면 안에서 소거 가능한 적탄을 제거.
- 오른쪽 아래 J·K·L 사각형 스킬 칸과 임시 이미지를 배치하고 J·K의 남은 쿨타임을 흰색 숫자로 표시. 필살기는 쿨타임 대신 에너지에 따라 사용 가능 상태를 표시.
- 이동·집중과 J·K·L을 함께 입력할 수 있도록 연결.
- 일관된 어두운 남색 판타지 스타일로 속사, 보호막, 산탄, 필살기 아이콘을 이미지 생성 기능으로 제작. 청록색 연속 탄환, 푸른 방패, 청록·주황 산탄, 보라·금색 별 폭발을 각각 표현한 글자 없는 시험용 이미지.

## 확인한 테스트

- Unity 6000.3.21f1 비대화형 EditMode 59건, PlayMode 6건 통과.
- 스킬 시간·에너지, 보호막, 산탄, 필살기 탄막 소거, 동시 입력, 아이콘 자원과 UI 배치 계산 확인.
- 사격 도중 J를 눌렀을 때 남은 사격 대기 시간 감소 확인.

## 남은 문제와 검증

- 필살기의 적 전체 피해 80은 이벤트 요청까지만 연결됨. 적 체력·처치와 에너지 보상은 적 구현 이후 연결 필요.
- 게임 화면의 아이콘·숫자 가독성과 스킬 밸런스, 실행 파일 빌드는 확인하지 않음.
- 스킬 이미지와 수치는 초기 시험용이며 최종 아트와 밸런스는 미확정.
- 기존 설정·키 변경 UI 작업은 이후 일정에서 계속 진행.
