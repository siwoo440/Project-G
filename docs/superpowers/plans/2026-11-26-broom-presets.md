# 캐릭터별 빗자루 프리셋 구현 계획

**목표:** 캐릭터별 최대 다섯 개의 명명된 여덟 부위와 제작 마법 참조·유지 우선순위를 저장하고 전체 검증 후 적용한다.

**구조:** 실제 보유 사본과 기존 편성 저장을 읽는 프리셋 저장소를 추가한다. 적용 전 대상 캐릭터, 모든 개별 부품, 중복·타 캐릭터 장착, 마법 참조·연구·예상 공격력 한도를 검증한다. 검증 실패 시 기존 장착과 프리셋은 변경하지 않는다. 검증 통과 후 전체 부품과 마법을 확정하고 기존 현재 장착 자동 저장을 갱신한다.

---
## 작업

- [x] 기존 빗자루와 마법 저장의 버전·개별 ID·복제본·삭제 보호를 확인하고 기존 저장을 바꾸지 않는 호환 경로를 정한다.
- [x] 독립 시험 키에서 캐릭터별 5개 제한, 이름·복제·삭제와 재실행 복원 실패 시험을 작성하고 저장소를 구현한다.
- [x] 부품 누락·분해·타 캐릭터 장착·부위 오류·중복, 마법 누락·연구·한도 부족에 대해 실제 적용 전 전체 취소 시험을 작성한다.
- [x] 모든 예상 부품과 세트·조건부 공격력을 같은 시점에 합산하고 검증 후 실제 여덟 부위와 마법 우선순위를 한 번에 확정한다.
- [x] 기본 부품 일괄 복원과 실패 사유, 현재 장착 유지·취소 및 비교를 검증한다.
- [x] 조립 UI에 프리셋 목록과 저장·적용·복제·이름 변경·삭제 및 필터를 연결하고 작은 화면의 텍스트·겹침을 점검한다.
- [ ] 실제 집중·장비 변화와 프리셋 교체의 마법 한도, 자동 해제·복구, 저장·강화·쿨타임 보존을 검증한다.
- [x] 검증 사본과 D:\Project-G에서 전체 PlayMode를 실행하고 사용자 변경과 파일 무결성을 확인한다.
- [ ] README, 일차 기록, 기획서 9.3·9.7·16을 실제 범위에 맞게 갱신하고 하나의 일차 커밋을 main에 푸시한다.

## 검토 경계

- 같은 마법 구성을 가진 서로 다른 도감 사본의 식별자와 참조 삭제 보호.
- 필수 부품이 없거나 다른 캐릭터가 장착한 경우 적용 전 전부 취소.
- 새 조합의 세트와 조건부 효과를 포함한 소수 마법 공격력 경계.
- 다섯 개 상한, 빈 슬롯, 잘못된 저장과 이전 버전 읽기.
- 적용 실패·취소 시 여덟 부위, 두 마법, 우선순위와 저장의 불변성.
