## 점수 지급과 획득 숫자

시험 적 처치마다 100점, 피격 없이 적탄 근접 판정을 통과할 때마다 10점을 합산한다. 적의 명중·이탈과 실제 피격은 점수를 지급하지 않는다. 적과 적탄의 기존 판정에서 보상을 한 번씩 연결한다. 정식 점수 산식, 생존 점수, 보스 패턴 무피격 보너스는 아직 확정되지 않았다.

왼쪽 위 연속 적중 정보 아래에 출격 점수를 표시한다. 새 획득 숫자는 점수 아래에 나타나고, 연속 획득 시 이전 숫자가 한 줄씩 위로 밀려 올라간다. 각 숫자는 약 1.6초 뒤 서서히 사라진다. 동시에 보이는 숫자는 최근 세 건이다. 한꺼번에 더 많이 획득해도 모든 점수가 합계에 반영된다.

게임을 일시정지하거나 레벨업 보상을 고르는 동안 표시 시간이 멈춘다. 재출격하면 점수와 획득 숫자를 초기화한다. 기존 제작 이미지를 점수판에 재사용했다. `CombatHUD/ScoreReadout`에서 점수판, 문구와 숫자 위치를 편집할 수 있다.

## 검증

Unity 6000.3.21f1 Play Mode 38개 통과. 처치·그레이즈 중복 지급 방지, 이탈·피격 제외, 재출격 초기화, 실제 일시정지에 따른 표시 시간 보존을 점검했다.

Windows 1920×1080·1024×576에서 적 한 마리를 처치하고 탄환 두 발을 스쳐 점수 120과 세 개의 획득 숫자를 확인했다. 획득 숫자의 상승·만료 순서와 재출격 초기화도 확인했다. [1920×1080](../screenshots/3d-day-15-flight.png) · [1024×576](../screenshots/3d-day-15-hud-1024.png)

16일차는 하늘섬 외곽 스테이지의 지형, 적 출현과 웨이브, 전투 시간과 전체 소요 시간의 분리 기록을 연결한다.
