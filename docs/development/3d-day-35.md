# 3D 35일차 | 베라의 상단 프로펠러 마도 포대

## 구현

- 출격 준비, 마을 장비와 결과 화면에 외부 마도 공학자 베라를 연결했다. 기획서의 정면 일러스트와 Q·R 아이콘을 사용했다.
- Q 마도 포대는 베라의 현재 비행 위치에 포대 한 기를 배치한다. 다리 없는 황동·에메랄드 본체 위의 프로펠러가 회전하며 본체는 위아래로 부유한다. 베라가 이동해도 포대는 설치 지점에 머문다.
- 기본 수명은 8초, 발사 간격은 1초, 포대탄 피해는 10이다. 새 설치는 같은 포대 한 기를 새 지점으로 교체한다. 진지 구축 1을 고르면 11초, 교차 사격 1을 고르면 사격 간격 0.75초를 적용한다.
- 포대 중심 2m 이내의 베라 기본·집중 자동탄은 피해가 20% 증가한다. HUD에 현재 수명과 보너스를 표시한다.
- R 교차 광선은 플레이어 위치와 무관하게 실제 포대에서 나가며 경로상의 적에게 피해 200을 준다. 지형에서 막히며 포대를 설치하지 않았거나 만료됐을 때 에너지 100을 보존하고 슬롯을 어둡게 표시한다. Q의 마력 25와 포대의 사거리 30m는 3D 시험값이다.
- `VeraTurretSite/Hover` 안에서 본체, 최상단 프로펠러, 표적 추적부, 마력 포구를 직접 편집할 수 있다.

## 검증

- Unity 6000.3.21f1 PlayMode 80개 통과. 실제 설치 좌표 고정, 프로펠러 회전, 첫 포대탄 10 피해, 파일럿이 설치 반경을 벗어났을 때 직접 공격 배율 복원, 광선 200 피해, 포대 교체·8초 만료·필살기 에너지 보존을 확인했다.
- Windows 1920×1080 자동 실행에서 베라의 실제 선택, 포대의 발사와 광선, 결과 스탠딩과 같은 캐릭터 재출격을 확인했다. 사용자 직접 플레이와 최종 포대 모델은 후속 검증으로 남았다.
