## 확인한 기획 규칙과 시험값

- 체력형 생존, 체력 0 시 출격 실패, 피격 후 무적 1초는 기획 규칙이다.
- 초기 시험값은 최대 체력 100, 일반 적탄 피해 10이며 강한 공격의 피해는 개별값이다.
- 필살기 에너지 초기 시험값은 시작 0, 최대 100, 사용 비용 100이다.
- 시험 충전량은 일반 적 처치 +2, 중간 보스 +10, 최종 보스 +20, 그레이즈당 +1이다. 보스와 일반 적 처치 보상은 중복하지 않는다.
- 그레이즈는 피격을 피하며 범위에 진입할 때 적용하고 탄환별 반복을 제한한다. 탄환당 1회가 시험 기준이다.
- 시험값은 실제 구현과 플레이 검증 결과에 따라 조정한다.
