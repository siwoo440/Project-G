# 5일차 : 두 캐릭터와 스킬 UI 크기 조정

---
## 완료한 작업

- 속사형 기본·집중 공격 적중 시 시험 피해 보너스 1%p 누적, 최대 50%, 마지막 적중 2초 뒤 초당 2.5%p 감소. 스킬 탄환은 누적과 보너스 대상에서 제외.
- 저격형은 일반 14·0.60초, 집중 30·1초 시험 사격과 적 1체 추가 관통. 표시된 약점 적중 시 피해 50% 추가.
- 저격 J는 전방 관통탄 100·쿨타임 10초, L은 시험 광선 220·에너지 100과 광선 안 소거 가능한 적탄 제거.
- 두 캐릭터의 공격을 확인할 임시 표적과 약점 표시를 추가. 정식 적과 보스의 구현은 6일차.
- 정식 선택 화면을 만들기 전 전투에서 F1 속사형, F2 저격형을 선택하도록 시험 기능을 추가. 변경 시 현재 위치에서 체력·자원·누적 상태를 초기화.
- 오른쪽 아래 스킬 정사각형 칸의 가로·세로 크기를 기존의 2.5배로 조정. 작은 화면에서는 화면 경계를 넘지 않도록 크기를 제한.
- 캐릭터 선택·출격 준비 화면의 정보와 배치를 아래 초안으로 정리.

---
## 캐릭터 선택·출격 준비 UI 시안

- 16:9 화면에서 상단은 화면 이름과 뒤로 가기, 왼쪽은 속사형·저격형 선택 목록, 가운데는 선택 캐릭터 임시 초상 및 소속, 오른쪽은 일반·집중 공격과 패시브·J/K/L 설명, 하단은 출격 버튼과 키보드 조작 안내.
- 공용 K의 장착 상태를 표시하고 교체 선택지는 선택 가능 시점에만 제공. 키보드로 선택·이동·확정·뒤로 가기를 지원.
- 속사형은 누적 화력과 감소 규칙, 저격형은 관통과 표시된 약점 피해를 비교할 수 있도록 표기. 체력 100과 시험값은 임시 수치로 구분.
- 캐릭터 이름·외형·비행 장비 및 상세 설정은 미정으로 유지. 이 화면은 문서상 시안이며 실제 화면 구현·전투 연결은 10일차 예정.

---
## 확인한 테스트

- Unity 6000.3.21f1 비대화형 EditMode 67건, PlayMode 8건 통과.
- 누적 상한·유지·감소, 탄환별 중복 차단, 저격 관통과 약점, J 쿨타임, L 범위와 적탄 소거, 자동 사격 표적 적중, F1/F2 선택과 스킬 칸 배치 확인.

---
## 남은 문제와 검증

- 표적은 피해 수치를 쌓는 시험 도구이며 정식 적 체력·처치·보스 부위 시스템이 아님. 적별 피해와 처치 에너지, 필살기 요청 연결은 6일차에 진행.
- 저격형 J/L은 기존 스킬 아이콘을 임시로 사용하므로 전용 이미지가 필요. 광선 폭과 약점 면적은 시험값이며 시각적 공정성 확인 필요.
- 실제 게임 화면에서 2.5배 스킬 UI의 가독성·탄막 가림, 캐릭터별 밸런스 및 실행 파일 빌드는 미검증.
- 임시 선택은 정식 출격 화면이나 저장 설정이 아님. 설정·키 변경 UI도 미구현.
