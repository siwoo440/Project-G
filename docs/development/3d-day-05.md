# 3D 5일차 입체 탄막과 적탄 재사용

---
## 구현

- 조준 1발, 부채꼴 7발, 입체 고리 12발, 회전 나선 4발의 공용 발사 규칙을 추가했다. 1~4로 고르고 T로 연습을 전환한다.
- 적탄 풀은 기본 24개를 준비하고 최대 128개까지 사용한다. 피격·지형 접촉·사거리 130 월드 단위·수명 8초에 도달한 탄을 회수한다. 재사용할 때 거리·수명과 피격·그레이즈 상태를 초기화한다.
- 제작한 조작 안내판에 선택한 탄막과 연습 상태를 표시한다.

---
## 검증

- Unity Play Mode 12개 통과. 네 배열의 발사 수, 고리의 위·아래 방향, 적탄 128개 상한과 사거리·시간 만료 회수 및 재사용을 확인했다.
- Windows 1920×1080 시험 빌드에서 고리탄 12발 발사와 화면을 확인했다.
- 최대 탄수에서의 실제 GPU 프레임 시간, 직접 회피 가독성, 다른 PC는 검증 전이다. 6일차는 일반 마물의 3D 모델·애니메이션과 피격 후 체력바다.
