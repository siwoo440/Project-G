# 3D 33일차 | 세라 근접 돌파와 결과 화면 재배치

## 구현

- 출격 준비와 마을 시설에 세라를 추가했다. 기획서 정면 일러스트와 Q·R 전용 아이콘, 세라의 빗자루 장착 상태가 같은 조종사로 이어진다.
- 근거리 결의는 적 중심과의 실제 3D 거리가 1.5m 이내인 직접 공격에 피해 25%를 더한다. 출격의 근거리 돌파 1은 적용 거리 2m, 검기 확장 1은 Q 너비 25% 증가로 적용한다.
- Q 돌파 검기는 8초 대기, 대상당 70의 시험 피해를 주고 같은 방향으로 0.25초 동안 최대 4m 돌파한다. R 천공 연참은 에너지 100을 사용해 전방에 40 피해의 검기를 다섯 번 적용한다. Q 마력 25와 검기 사거리·고도 범위·연참 간격은 3D 시험값이다.
- 검기 타격은 상하·가로·전방 위치를 확인하고 지형 뒤의 적을 제외한다. 돌파는 기존 비행 경계와 지형 접촉 규칙을 사용한다.
- 결과 씬의 왼쪽에는 전투에 사용한 조종사의 기존 스탠딩 일러스트를 원래 비율로 표시한다. 오른쪽 패널에는 기존 전투 기록, 재화 아이콘과 수치, 같은 조합 재출격 및 메인 화면 버튼을 배치했다.
- Unity 하이러키에서 `SortieResult/PortraitArea/StandingIllustration`과 `SortieResult/Panel`을 따로 편집할 수 있다. 공용 에셋 `PilotStandingArt`에서 준비·결과가 참조하는 캐릭터 그림을 관리한다.

## 검증

- Unity 6000.3.21f1 PlayMode 78개 통과. 세라의 Q 근거리·장거리 피해, 높은 표적 제외, 돌파 4m와 벽 정지, 벽 뒤의 적 보호, R의 다섯 차례 피해와 에너지 소비를 확인했다.
- 실제 클리어와 실패 테스트에서 각각 아리아와 리안의 스탠딩이 표시되고 실패 후 같은 조합의 재출격을 확인했다.
- Windows 격리 실행 검증으로 실제 결과에 사용한 조종사 일러스트가 표시되고 좌우 영역이 겹치지 않는지 확인했다. 직접 플레이 밸런스와 결과 화면의 3D 모델 교체는 후속 작업이다.
