# 3D 31일차 아리아·리안 첫 과제와 후속 성장

---
## 첫 과제

실전 첫 웨이브부터 아리아의 기본·집중 자동 사격이 마물에게 준 유효 피해 50회, 리안의 약점 유효 피해 10회를 한 출격 단위로 센다. 리안은 기본·집중 사격과 Q·R의 실제 약점 피해를 집계한다. 무적에 막힌 피해, 연습 표적, 보조탄의 피해를 집계에서 제외한다.

정상 종료에서 최초 완료를 저장할 때 조율의 증표 하나를 출격 영수증과 함께 지급한다. 이후 출격에서는 같은 과제를 다시 지급하지 않는다. 강제 종료 복구는 참여 기본분을 처리한다. [아리아 첫 과제](../screenshots/3d-day-31-aria-task.png) · [리안 첫 과제](../screenshots/3d-day-31-rian-task.png)

## 후속 성장

강화 공방의 **후속 성장**에서 노드당 천공 결정 18개와 해당 조종사의 조율의 증표 1개를 소모한다. 해금과 비용은 같은 저장에서 확정된다. 이번 출격에 같은 분기 1단계를 선택하면 해금한 2단계가 카드 후보에 들어간다.

| 조종사 | 후속 노드 | 효과 |
|---|---|---|
| 아리아 | 추격 사격 2 | 누적 +30% 이상에서 같은 적에게 5회 적중하면 피해 5의 추가탄. 초당 1회 |
| 아리아 | 확산 포화 2 | 집중 포화 중 0.5초마다 35m 안의 가까운 적에게 피해 5의 추가탄 |
| 리안 | 약점 사냥 2 | 약점 적중 시 Q 재사용 대기시간 0.2초 감소. 초당 1회 |

추격·확산의 추가탄은 연속 적중을 올리지 않는다. 리안 관통 궤도 2의 약점 연산 순서와 추가 변형은 결정 대기다.

## 검증

Unity 6000.3.21f1 Play Mode 75개로 최초 보상 중복 방지, 재화 부족·타 조종사 구매 차단, 같은 저장의 해금 복구, 두 추가탄과 약점 쿨타임 제한을 확인했다.

Windows 1920×1080에서 체력을 늘린 검증 표적에 실제 투사체를 발사했다. 아리아 49→50회와 리안 약점 9→10회의 경계, 아리아의 비자동 사격과 리안의 몸통 적중 제외, 정상 실패 결과의 최초 증표 지급을 확인했다. 실제 공방에서 아리아 추격 사격 2·리안 약점 사냥 2를 구입하고 같은 분기 1단계의 적용 전후 후보 자격을 확인했다. 1024×576 재실행에서 아리아 해금과 재화가 복원됐다. [아리아 공방](../screenshots/3d-day-31-aria-growth.png) · [리안 공방](../screenshots/3d-day-31-rian-growth.png) · [재실행 공방](../screenshots/3d-day-31-restore-growth.png)

직접 플레이의 해금 체감과 5~8회 연속 레벨업에서의 등장 빈도는 미검증이다. 32일차는 루미의 3D 유도 전투와 전용 기술을 다룬다.
