# UI 선명도 후속 수정

---
## 변경 내용

- 메인 화면, 마을, 출격 준비, 결과 화면의 화면 오버레이에 픽셀 정렬을 켰다. 비행 시험과 외곽 항로는 기존 설정을 유지한다.
- 여섯 게임 씬의 나눔고딕 작은 굵은 글자는 기본 크기와 자동 맞춤 최대값을 20% 올리고 일반 굵기로 바꿨다. 큰 제목과 일반 굵기 본문은 기존 설정을 유지한다.
- 긴 첫 사건 기록을 포함한 일반 본문의 크기는 바꾸지 않는다. 첫 번째 일괄 확대 후보에서 본문이 잘리는 회귀가 발견되어 범위를 조정했다.

---
## 검증

- Unity 6000.3.21f1 배치 PlayMode 92개 통과, 실패·건너뜀 0개. 여섯 씬의 화면 오버레이 픽셀 정렬, 상점 상품명, 첫 사건 기록 본문, 웨이브 표시와 기존 전투·정산·재출격 시험을 포함한다.
- 1024×576 렌더 텍스처에서 상점과 전투 화면을 확인했다. 상점은 기존 글자와 확대·일반 굵기 후보를 비교했다. 검증 캡처는 캔버스를 임시로 카메라 공간에 연결한 결과이며 실제 플레이어의 화면 오버레이와 동일한 캡처가 아니다.
- 메인·출격 준비·결과 화면은 같은 캡처 방식으로 유효한 이미지를 얻지 못했다. 다른 해상도와 4:3 화면의 시각 검증, Unity Game 뷰 및 Windows 플레이어의 직접 화면 검증은 미실행이다.

## 캐릭터 초상화 버튼

- 장비 상점과 강화 공방에서 공통으로 쓰는 캐릭터 선택 버튼을 `103×103` UI 단위로 키웠다. 기존 이름과 선택 기능은 유지하고, 인물 초상화와 단색 배경을 별도 UI 이미지로 배치했다.
- 아리아·리안·루미·세라·녹스·베라·이리스의 투명 초상화 7종은 `Assets/ProjectG/UI/PilotPortraits/`에 저장했다. 배경색은 순서대로 청록·남색·보라·적색·짙은 보라·녹색·하늘색이다. 배경은 각각 씬의 `PortraitBackground` 이미지에서 변경할 수 있다.
- 이미지 생성 도구에 각 캐릭터의 기존 전신 일러스트를 인물 참조로, 아리아의 시안은 구도·화풍 참조로 제공했다. 공통 요청은 “기존 인물의 얼굴·머리·장식·의상을 유지한 정사각형 머리와 어깨 초상화, 판타지 애니메이션 화풍, 실제 투명 배경, 글자·테두리 없음”이다.
- 작은 이미지의 축소 계단을 줄이기 위해 초상화에 밉맵과 삼중 선형 필터를 적용했다. 상점 1024×576·1024×768과 공방 1024×576은 카메라 공간에 임시 연결한 렌더 텍스처로 확인했다. 실제 Windows 화면 오버레이와 수동 플레이는 확인하지 않았다.
- Unity 6000.3.21f1 배치 PlayMode 93개 통과, 실패·건너뜀 0개. 일곱 개의 다른 초상화·배경, 버튼 크기, 상점과 공방의 캐릭터 선택을 포함한다.
