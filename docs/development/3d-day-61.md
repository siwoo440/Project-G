# 3D 61일차: 마법 편성 한도와 자동 재편성

---
## 구현과 확인

- 정수 구성 비용이 현재 소수 마법 공격력을 초과하지 않도록 한도를 계산한다. 이전 반올림은 공격력이 비용보다 최대 0.5 미만으로 부족해도 편성을 허용할 수 있었다.
- 제작 화면에 내림한 편성 한도 대신 실제 소수 마법 공격력을 표시한다. 두 칸의 구성 비용이 현재 한도를 넘으면 우선순위가 낮은 슬롯부터, 동순위에서는 최근 편성한 슬롯부터 자동 해제한다.
- 한도가 돌아오면 자동 해제된 구성만 원래 슬롯에 복구한다. 저장된 구성, 전투 중 강화와 남은 쿨타임은 유지하고 직접 비운 슬롯은 복구하지 않는다. 이미 발사된 탄환은 유지하고 해당 슬롯의 지속 효과는 종료한다.

---
## 검증

- Unity 6000.3.21f1 배치 PlayMode 186개가 검증 사본과 `D:\Project-G`에서 각각 통과했다. 실패와 건너뜀은 0개다.
- 두 마법의 비용보다 공격력이 0.25 낮을 때 실제 초과 편성 해제, 동일 우선순위의 최신 편성 해제, 정확한 비용 경계의 복구 및 제작 화면 소수 표시를 시험했다.
- 실제 별빛 손잡이의 집중 공격력 증가와 종료로 자동 복구·재해제, 저장 구성·강화·남은 쿨타임 보존을 시험했다. 해당 시험의 경계는 임시 불이익값으로 만든 뒤 원본을 복구했다.
- 기존 시험에서 낮은 우선순위 우선 해제, 직접 해제 제외, 지속 효과 종료와 이미 발사된 탄환 보존도 함께 검증했다.

## 남은 작업

- 60일차의 화염 궤적·폭발, 별빛 장식·매의 명중 피해 등 남은 빗자루 특수 발동과 충격 저항·안정성의 실제 소비처는 미완료다. 냉기·번개·중력 전용 제작 마법과 공용 대시는 아직 없다.
- 62~63일차의 빗자루 프리셋·도감 구현 후 프리셋 교체에 따른 편성 한도, 자동 해제 및 복구를 다시 검증해야 한다. 정식 부품 3D 모델도 미제작이다.
- 56일차의 구성 아이콘·검색, 아군 연출 강도, 확장 연습 표적·경계와 실측은 미완료다. 정예·20/40처치 자연 플레이, 운영체제 강제 종료 재시험, 출격 준비 실제 렌더, 실제 모니터·다른 PC 수동 검증과 Steam 실연동은 실행하지 않았다.
