# 3D 14일차 강화 아이템과 전투 레이더

---
## 강화 아이템과 보조 장비

강화 아이템 9종과 I~V 등급을 추가했다. 시험 등급 확률은 50·25·15·7·3%다. 일반 적은 10%, 중간 보스는 적용 가능한 후보가 있을 때 1개, 최종 보스는 0개를 떨어뜨린다. 아이템은 초당 0.5 유닛씩 내려가며 20초 후 사라진다. 플레이어의 이동 경로가 반경 0.65 유닛 안을 지나면 전투 중 바로 획득한다.

공격 드론, 회전 칼날, 보호 장치를 레벨업 선택 후보에 추가했다. 드론은 다리 없이 위쪽 프로펠러로 비행하는 시험 모델을 사용한다. 피해량은 +60%, 사격 간격과 카드 순환 시간 감소는 각각 40%, 관통은 +3단계까지 누적된다. 시간제 보호막이 남아 있을 때 먼저 적용하며 최대 단계에 도달한 보상은 후보에서 제외한다.

## 전투 HUD와 정지 메뉴

- `CombatHUD/EnemyRadar`를 오른쪽 위에 배치했다. 원형 레이더의 위가 카메라 정면이며 북쪽 표식이 시점에 따라 움직인다. 활성 적의 수평 방향과 직선거리를 표시하고, 거리 글자가 겹치면 가까운 적의 숫자를 우선 표시한다.
- 경과 시간·Wave 번호·남은 적 수는 상단 중앙에 표시한다. 전투 화면 왼쪽 아래 조작 설명을 삭제하고 ESC의 조작 안내에서 키보드와 설명을 볼 수 있게 했다.
- 정지 제목 아래에 정지 시점의 경과 시간·Wave·남은 적 수를 배치했다. 왼쪽 버튼 중심 간격은 107 UI 단위로 통일했다. 정지·설정·포기 확인 패널과 버튼에는 제작한 이미지를 적용했다.
- UI 텍스처는 압축과 밉맵을 끄고 원본 해상도로 가져온다. 키보드 이미지는 1824×708로 내보냈다. 프로젝트의 에디터 설정 스크립트는 Unity Game View의 저해상도 옵션을 해제한다.

원형 레이더 프레임, 정지 메뉴 패널, 버튼 배경은 내장 이미지 생성 도구에서 제작했다. 프레임과 그림은 PNG, 거리·버튼 문구·키 배정은 편집 가능한 UI 요소로 구성했다.

## 검증

Unity 6000.3.21f1 Play Mode 36개 통과. 강화 아이템 획득·유효 시간·보상 상한, 보조 장비의 실제 효과, 보호막 우선순위, 레이더의 방향·거리·표시 제거, 정지 메뉴의 시간과 키 재배정을 검증했다.

Windows 1920×1080·1024×576 시험 빌드에서 레이더와 정지 메뉴, 강화 아이템 획득을 확인했다. Unity의 저해상도 옵션 해제는 격리 에디터에서 검증했으며 사용자의 현재 Game View 창은 직접 확인하지 않았다. 중간·최종 보스의 드롭 규칙은 시험용 적으로 검증했다. 정식 보스전은 후속 일차 범위다.

다음 15일차는 전투 점수와 연속 획득 숫자 UI를 구현한다.
