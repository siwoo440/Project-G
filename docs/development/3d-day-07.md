# 3D 7일차 일반 적 이동과 왼쪽 아래 비행 구도

---
## 구현

아리아의 화면 위치가 중앙 조준점 왼쪽 아래에 오도록 카메라를 오른쪽 뒤로 옮겼다. 조준점과 탄착점 검증을 위해 근거리·고고도 표적을 새 중앙 광선에 맞췄다.

Y로 시험을 시작하면 조준형이 하강하고, 확산형이 오른쪽으로 이탈하고, 돌진형이 비행체 방향을 지나간다. 각 유형은 두 종류의 탄막을 사용한다. 세 마물의 이동 좌표와 탄막, 날개 재질은 Hierarchy와 Inspector에서 수정할 수 있다.

---
## 검증

- Unity Play Mode 15개 통과. 새 화면 구도에서도 기본탄과 집중탄의 기존 조준 시험이 통과했다. 세 적의 출현·복수 패턴·경로·이탈을 확인했다.
- Windows 1920×1080 시험에서 세 적과 활성 적탄 46발을 확인했다. 좌하단을 원점으로 하는 화면 좌표에서 아리아 몸통은 약 (0.38, 0.37), 조준점은 (0.50, 0.50)이다.
- 사람이 직접 피할 때의 난이도와 다른 화면 비율·PC는 검증 전이다.
