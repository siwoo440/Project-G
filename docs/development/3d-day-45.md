## 파일과 코드

- 실제 배포 씬 여섯 개의 전이 의존 214개를 Unity AssetDatabase로 확인했다. 임시 편집 도구와 테스트까지 포함한 에디터 인벤토리는 290개였다. 설정, 프로젝트 라이선스와 코드의 동적 참조를 별도로 확인했다.
- 조준탄이 쓰는 `FlightArt/ThreatEmber.mat`만 남기고, 교체된 기존 재질 `FlightPrototype/Bolts/ThreatEmber.mat`와 해당 .meta를 지웠다. 기존 GUID는 변경 전의 전체 저장소 검색에서 .meta 하나에만 나왔다.
- 기본 템플릿 `SampleScene`을 배포 목록에서 제외했다. 원본은 Unity 템플릿 설정이 참조해 유지했다.
- 적탄별 LateUpdate를 하나의 풀로 옮겼다. 같은 프레임의 기체 위치와 시간을 한 번 읽고 활성 탄만 처리한다. 회수 뒤 다음 탄이 빠지지 않도록 순서를 유지하고, 지형·버전별 탄막 외형·그레이즈·판정 수치는 그대로다.

## Windows 측정

Unity 6000.3.21f1 Windows 64비트, 1920×1080, VSync 해제, 외곽 항로의 같은 카메라로 진행했다. 활성·생성 탄은 모든 회차에서 128발이었다. 매회 준비 60프레임과 표본 180프레임으로, 세 회차에서 계산한 지표의 중앙값을 기록했다. 범위 조회는 같은 위치·반경에서 프레임마다 여덟 번 반복했다.

| 지표 | 이전 | 이후 |
| --- | ---: | ---: |
| 프레임 중앙 시간 | 0.820 ms | 0.714 ms |
| 프레임 시간 95백분위 | 1.162 ms | 1.028 ms |
| 활성 탄 반경 조회 1회 | 0.00957 ms | 0.00371 ms |
| Unity 할당 메모리 | 100,454,730 B | 99,446,651 B |
| 관리 힙 사용량 | 5,627,904 B | 5,632,000 B |

PlayMode 90개 통과. 측정은 같은 PC의 자동 비교이며 다른 PC의 실제 플레이 성능은 확인이 필요하다. [탄막 비교 화면](../screenshots/3d-day-45-projectile-benchmark.png)
