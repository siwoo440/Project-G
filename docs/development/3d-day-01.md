# 3D 1일차 첫 비행과 추적 카메라

---
## 구현

- 하늘섬 시험 씬에 임시 아리아, 기본 빗자루, 원근 추적 카메라와 키 안내 배치
- WASD 전후·좌우 이동, Space 상승, 양쪽 Ctrl 하강 연결
- Hierarchy에서 시험 모델·지형·카메라 수정 가능
- `FlightPrototype`을 Windows 시작 씬으로 등록하고 Unity 6000.3.21f1 버전 기록

---
## 확인한 시험

| 환경 | 확인 결과 |
|---|---|
| Unity Play Mode | 2개 통과. 여섯 방향 키 입력, 뒤쪽 원근 카메라 추적, 화면 구도, 시작 씬 등록과 Hierarchy 확인 |
| Windows 64비트 시험 빌드 | Direct3D 12에서 실행 성공. 같은 키 입력 경로로 전진 5.73, 상승 0.66 월드 단위와 동일한 카메라 이동 확인 |
| 실제 화면 | Windows 시험 실행에서 1920×1080 PNG 캡처 |
