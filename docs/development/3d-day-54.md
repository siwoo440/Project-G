# 3D 54일차: 마법 연구 자격과 공용 해금

---
## 구현

- 한 조종사의 숙련도와 해당 조종사의 연구 과제를 함께 검사한다. 일반·심화·특수 자격은 각각 숙련도 20·60·120과 일반 적 10마리·중간 보스·최종 보스 과제를 사용하며, 앞 단계의 공용 자격도 필요하다.
- 본편에 지정된 웨이브의 일반 적과 중간 보스 처치를 출격 중 기록하고 정상 클리어·실패 정산 때 해당 조종사에게 확정한다. 강제 종료 복구는 기존 참여 보상만 지급한다. 서로 다른 출격의 처치 수나 서로 다른 조종사의 숙련도·과제는 합산하지 않는다.
- 기존 제작 선택지 101개에 기획서의 초기·일반·심화·특수 단계와 분류별 선행 ID를 연결했다. 초기 실요소 28개와 효과 없음을 무료로 제공하고, 유도 조준은 유도 궤적에서 무료 연동한다.
- 자격·모든 선행 요소·재화를 확인한 연구만 공용 결정과 골드를 한 번 차감하고 영구 해금 ID와 함께 같은 저장에 확정한다. 중복 구매와 무료 연동 구매는 차단한다. 저장 조합 전체가 해금됐는지 확인하는 경로도 추가했다.
- 기존 저장 형식을 유지하며 새 연구 과제 필드가 없는 저장의 숙련도와 재화를 보존한다. 과거 클리어는 어느 조종사의 새 과제였는지 확인할 수 없으므로 연구 과제로 소급하지 않는다.

---
## 검증

- Unity 6000.3.21f1 배치 PlayMode 135개 통과, 실패·건너뜀 0개. 기존 저장·전투·정산·재출격 회귀를 포함한다.
- 서로 다른 조종사의 숙련도와 과제 합산 금지, 서로 다른 출격의 처치 수 합산 금지, 일반·심화·특수 자격의 계정 공유와 저장 재열기를 확인했다.
- 실제 본편 웨이브 적의 처치가 정산 전에는 미확정이고 정상 실패 정산에서 기록되는 것을 확인했다. 강제 종료 복구와 중복 정산에서 추가 과제가 생기지 않는 경계도 시험했다.
- 101개 제작 선택지와 연구 노드의 일치, 초기 선택지 29개, 선행 ID 존재 및 순환 없음을 검사했다. 선행 누락·자격 부족·중복 연구의 거절, 공용 재화 차감, 유도 조준 무료 연동과 재실행 후 복원을 확인했다.
- 연구 필드가 없는 이전 저장에서 숙련도·결정·골드가 보존되고 이후 새 연구 과제를 정산할 수 있음을 확인했다.

---
## 미검증과 다음 작업

- 고정 상점, 무료 보상 선택권과 보류는 55일차에 구현한다. 연구 목록의 조작 화면과 잠금된 저장 마법의 실제 편성 제한은 56일차에 연결한다. 현재 추가 마법은 시험용으로 접근 가능하다.
- 실제 스테이지 정예 배치, 보스탄별 흡수 허용 분류, 60초 반복 실측, Windows 실제 화면·조작과 다른 PC·Steam 실연동은 미검증이다.
- 55일차에는 연구 상점과 정상 출격의 지정 격파 보상, 적격 후보가 없을 때 보류되는 무료 선택권 및 중복 방지를 구현한다.
