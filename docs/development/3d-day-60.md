# 3D 60일차: 빗자루 효과와 조립 목록

---
## 구현 범위

- 조립 화면에 부위별 보유 부품의 목록 넘김을 추가해 기존 9개 제한을 제거했다. 장착 중인 사본과 다른 캐릭터의 사본은 기존 규칙을 유지한다.
- 서로 다른 희귀도의 같은 세트 부위를 합산하고 비교 화면에 세트 변화를 반영한다. 80종 부품의 상시·집중·마력 조건 수치 115개를 기획 항목과 대조했다. 동일 능력치·조건의 개별 효과는 수치가 큰 두 개를 적용한다. 집중과 실제 마력 30 이하의 변화에 따라 수치를 다시 계산한다.
- 폭풍·수호·수맥·별빛·매·그림자의 해당 2·4세트 기본 수치와 화염 2세트 탄속, 화염 개별 탄속·사거리를 연결했다. 현재 냉기·번개·중력 제작 마법이 없어 해당 속성 전용 효과의 실전 적용은 보류했다.
- 수호 보호막의 최대 체력 30% 내림 상한과 기여분별 만료를 적용한다. 기존 스킬·아이템 방어와 피해 감소를 먼저 처리하고 남은 피해를 만료가 빠른 보호막부터 흡수한다. 수호 4·8세트와 몸체·마력석·장식의 피격·파괴 효과, 서리 8세트의 피격 소거를 실전 적탄에 연결했다. HUD에 장비 보호막 수치를 표시한다.
- 수맥의 마력 경계·대시·첫 명중 회복과 그림자의 그레이즈 회복·반격탄, 별빛 8세트의 제작 마법 첫 명중 추가탄을 연결했다. 첫 유효 명중은 같은 시전에서 공유하며 추가탄은 재귀 발동하지 않는다.
- 세라의 실제 돌파에 부품의 지속시간·속도와 쿨타임 감소를 적용한다. 쿨타임 배율을 먼저 적용한 다음 고정 초를 뺀다. 폭풍 8세트와 해당 부품의 돌파 종료 추가탄·마력 회복·일시 속도를 연결한다. 별도 공용 대시는 아직 없다.

## 검증

- Unity 6000.3.21f1 배치 PlayMode 184개가 검증 사본과 `D:\Project-G`에서 각각 통과했다. 실패와 건너뜀은 0개다.
- 후보 페이지, 세트 구성과 교체 미리보기, 집중·마력 조건, 실제 화염 마법, 보호막의 독립 만료와 기존 방어 우선순위, 피격·실제 적탄 소거를 확인했다.
- 그레이즈 누적·쿨타임, 실제 추가탄과 적 충돌·비재귀, 세라 돌파의 수치와 종료 발동, 제작 마법 최초 유효 명중의 중복 방지와 마력·추가탄을 시험했다.
- 기본·조건부 효과 115개는 14.10의 추출 데이터와 자동 대조하여 누락·초과·미분류 0개를 확인했다. 이것은 모든 특수 발동 효과의 완료를 뜻하지 않는다.

## 남은 작업

- 60일차는 **부분 완료**다. 화염 궤적·폭발, 별빛 장식의 명중 피해, 매 세트·장식의 원거리 명중 피해와 나머지 명중 발동 효과를 연결하고 각각 쿨타임·횟수·실제 피해를 검증해야 한다. 냉기·번개·중력 전용 마법이 없어 해당 세트의 속성 발동은 검증할 수 없다.
- 충격 저항과 비행 안정성은 수치·비교에 표시하지만 실제 충돌·안정성 소비처의 연결은 확인이 필요하다. 공용 대시도 후속 구현이다.
- 61일차의 조건 변화에 따른 마법 자동 해제·재편성 종합 검증, 62~63일차 프리셋·도감 및 정식 부품 모델은 미완료다.
- 56일차의 구성 아이콘·검색, 아군 연출 강도, 확장 연습 표적·경계와 실측은 미완료다. 정예·20/40처치 자연 플레이, 운영체제 강제 종료 재시험, 출격 준비 실제 렌더, 실제 모니터·다른 PC 수동 검증과 Steam 실연동은 실행하지 않았다.
