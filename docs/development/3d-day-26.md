# 3D 26일차 영구 정산과 강제 종료 복구

---
## 정산과 저장

실전 첫 웨이브가 열릴 때 조종사와 고유 출격 ID를 저장한다. 클리어는 숙련도 20과 천공 결정 6개, 참여 실패·포기·다시하기는 숙련도 10과 천공 결정 3개를 지급한다. 조율의 증표는 조종사별 누적 숙련도 60마다 1개를 지급한다. 참여 전 종료와 연습 씬에는 영구 보상이 없다. 실전의 조종사는 첫 웨이브부터 고정한다.

저장 파일은 `Application.persistentDataPath/Flight/progress-v1.json`이다. 영구 재화·기본 선택 해금·정산 영수증을 한 스냅샷에 기록한다. 기록한 임시 파일을 같은 볼륨에서 교체하며, 이전 사본은 `.bak`에 보관한다. 동일 출격 ID가 다시 들어오면 재화를 재지급하지 않는다. 같은 프로필을 두 실행에서 동시에 정산하지 않도록 파일 핸들을 배타적으로 연다.

결과의 지급 내역, 준비 화면의 누적 재화, 타이틀의 중단 출격 안내를 씬 하이러키에 배치했다. 새 게임은 출격 흐름만 새로 열고 영구 성장을 보존한다. 캐릭터 고유 과제와 직접 구매 해금은 31일차 범위다.

## 검증

Unity 6000.3.21f1 Play Mode 70개로 최초 보상, 출격 ID 중복 방지, 다른 저장 인스턴스의 복구, 숙련도 60 경계와 조종사별 증표 보존을 확인했다.

Windows 1920×1080에서 아리아 클리어로 숙련도 20·천공 결정 6을 확인했다. 같은 격리 저장에 리안의 첫 웨이브 참여를 기록하고 검증용 Windows 프로세스를 강제 종료했다. 1024×576 재실행에서 숙련도 10과 천공 결정 3만 지급했고, 다시 실행해도 증가하지 않았다. 이어진 리안 피격 실패까지 실행한 뒤 저장의 천공 결정 12와 두 조종사의 숙련도 각 20을 확인했다. [클리어 정산](../screenshots/3d-day-26-settlement.png) · [중단 복구](../screenshots/3d-day-26-recovery-1024.png)

파일 교체 명령이 동작하는 순간의 전원 차단과 다른 PC의 실기 플레이는 미검증이다. 27일차는 첫 출격 안내와 여러 화면비의 UI를 다룬다.
