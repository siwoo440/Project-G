# 10일차 : 메뉴와 전투 결과 연결

---
## 완료한 작업

- 타이틀, 캐릭터 선택, 공용 스킬 선택 및 출격 준비를 시험 화면으로 연결했다. 아리아·리안의 팀 소속을 표시하고 스킬명은 기획안으로 구분한다.
- 전투 종료 시 처치·그레이즈·실제 피격·선택 카드와 전투 시간·전체 시간을 결과 화면에 표시한다. 재시도와 출격 준비 복귀 시 진행 손실 확인과 전투 객체 초기화를 연결했다. 이전 출격의 탄환·광선도 재시도 시 정리한다.
- 일시정지, 계속하기, 재시도, 준비 화면 복귀 및 설정을 키보드와 마우스로 조작하도록 연결했다.
- 이동·집중·J/K/L 입력의 키 변경, 중복과 예약 키 차단, 집중 방식과 판정 표시 설정의 저장을 연결했다.
- 화면 모드·지원 해상도·FPS 제한·수직 동기화의 설정을 추가했다. 실제 화면 변경은 사용자의 게임 내 적용 또는 독립 실행 시작 시에만 요청한다.
- 플레이어가 HUD와 겹칠 때 해당 HUD를 일시적으로 옅게 표시한다. 시험 UI는 기존 이미지 자산과 런타임 UI를 사용한다.
- 보상·숙련도·재료·과제는 아직 지급하거나 저장하지 않으며 결과 화면에 미구현으로 표시한다.

---
## 확인한 테스트

- Unity 6000.3.21f1 비대화형 배치 모드에서 EditMode 194건과 PlayMode 26건이 통과했다.
- 메뉴에서 출격, 실패 후 결과·확인·재시도, 선택한 캐릭터와 공용 스킬 유지 및 전투 기록 초기화를 자동 시험했다.
- 키 재지정과 중복 방지, 일시정지 및 설정 입력, 가상 화면 장치를 이용한 화면 설정과 저장, HUD 겹침 계산을 자동 시험했다. 시험에서는 실제 화면 해상도를 변경하지 않았다.
- 제한된 실행 환경의 Unity 라이선스 연결이 시간 초과되어 첫 배치 실행이 중단됐고, 정상 권한의 배치 실행으로 위 시험을 다시 수행했다.

---
## 남은 작업

- 실제 게임 화면에서 UI 배치와 한글 크기, 일시정지 화면의 겹침, 탄막·HUD 가독성과 조작감을 확인하지 않았다.
- 독립 실행 빌드의 실제 모니터 모드·해상도·FPS·수직 동기화 적용은 확인하지 않았다. 다른 세부 그래픽·오디오 옵션은 미구현이다.
- 영구 성장, 보상 지급, 재료, 도전 과제와 저장 복원은 11일차 이후 작업이다. UI와 콘텐츠 수치는 초기 시험용이다.
- 전체 시간·전투 시간과 보상 목표, 캐릭터별 밸런스 및 성능의 실측이 남았다.

---
## 다음 일차
