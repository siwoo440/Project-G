# 3D 41일차 | 자유 훈련과 마을 NPC 대화

---
## 자유 훈련

- 출격 준비의 **자유 훈련 F4**에서 현재 조종사로 연습을 시작한다. 자유 비행, 표적 사격, 마물 경로와 조준·부채꼴·고리·나선 탄막을 선택할 수 있다.
- F4로 설정을 다시 열어 반복 또는 한 번 실행, 현재 선택 다시 시작, 기존 연습 계속하기를 고른다. 연습을 초기화하면 기존 탄막과 표적이 제거되고 기체·체력·마력·카드 순서가 돌아온다.
- 자유 훈련에서는 표적과 적탄에 실제 판정을 사용한다. 경험치, 강화 조각과 본편 영구 보상 지급은 제외한다. 출격 준비로 돌아갈 때 현재 조종사를 유지한다.

---
## 마을 대화

- 서쪽 장비 상점의 상점 주인, 동쪽 강화 공방의 담당자, 북쪽 출격 안내원을 실제 3D 오브젝트로 배치했다. 가까이에서 F나 대화 버튼을 누르면 NPC가 대화 카메라를 바라보고 전용 화면이 열린다.
- 대화창은 화자, 순차 표시 대사, 오른쪽 선택지 세 개를 표시한다. F와 Enter는 대사를 펼치거나 다음으로 넘긴다. 숫자 1–3, 위·아래와 F 또는 Enter, 마우스로 응답을 고른다. Esc는 원래 마을로 돌아간다.
- 시설을 열기, 이용 방법 묻기, 인사 뒤 나가기의 세 분기가 있다. 실제 시설 선택은 기존 장비 상점·강화 공방·출격 준비를 호출한다. 마을의 E 직접 입장도 가능하다.
- `VillageWorld/VillageNPCs`에서 각 주민의 모델·대사·응답·거리와 `VillageHUD/NPCDialogue`에서 문장 프레임·글자·버튼을 편집한다. 지금 대사는 이 시제품의 테스트 문구다.

---
## 검증

- Unity 6000.3.21f1 PlayMode 87개가 통과했다. PlayMode에서 자유 훈련과 마을의 대화 범위, 도보 입력 차단, 설명 분기, 상점·강화 공방·출격 준비 전환을 검증했다.
- Windows 1920×1080과 1024×768 자동 입력에서 실제 보행로를 따라 세 NPC에게 접근하고 F로 대화했다. 상점과 공방의 UI를 열고 북쪽에서 출격 준비로 이동해 루미의 단발 고리 훈련과 영구 재화 보존을 확인했다.
