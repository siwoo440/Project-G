# 3D 10일차 아리아 속사와 비행·카드 조정

---
## 구현

- 일반 비행 최고 속도를 8에서 12로, 집중 비행을 4에서 6으로 수정했다. 기존 50% 집중 비율과 대각선 입력 정규화를 유지했다.
- 아리아는 기본탄·집중탄이 적중할 때마다 피해 보너스를 1%p씩 최대 50%까지 얻는다. 마지막 명중 2초 뒤부터 초당 2.5%p를 잃는다. 누적 보너스는 발사 시 정수 피해로 반영한다.
- Q 집중 포화는 3초 동안 자동 사격 간격을 70%로 줄인다. R 유성 탄막은 필살기 에너지 100을 소모해 화면 안 적탄을 제거하고 활성 적에게 피해 80을 준다. E 보호는 기존 동작을 유지한다.
- 첨부 PNG 다섯 장을 어둠·불꽃·물·자연·빛 아이콘으로 적용했다. 원본 알파와 Unity 참조를 유지했다.
- 2배로 확대했던 카드에서 가로·세로를 각각 70%로 조정했다. 캔버스 기준 현재 카드 128.8×193.2, 미리보기 100.8×151.2다. Q·E·R 슬롯 크기는 88×88이며, 카드 위에 정렬했다.

---
## 검증

- Unity 6000.3.21f1 Play Mode 21개 통과. 비행 속도, 카드 크기와 순환, 아리아의 누적·감쇠, Q 발동, R의 적탄 소거와 피해를 확인했다.
- Windows 시험 빌드 1100×620·1920×1080에서 자동 명중과 좌우 카드 순환, Q 카운트다운을 확인했다.
- 사용자의 Unity Game 뷰와 실제 수동 비행 체감, 이후 보스전에서의 성능과 밸런스는 확인 전이다.
