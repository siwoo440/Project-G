# 3D 59일차: 빗자루 제작·분해와 UI 가독성

---
## 구현

- 마을 공방에서 획득한 부품 종류와 해금된 등급을 선택해 확정 제작한다. 제작법은 해당 종류의 획득 등급과 그 아래 등급을 영구 해금하며 기존 상점 구매품과 시험용 세트 부품도 반영한다.
- 기획서의 등급별 결정·골드 제작비를 차감한다. 개별 부품의 분해는 기준 제작비의 절반을 각각 내림해 반환하고 강화에 쓴 재화는 반환하지 않는다.
- 캐릭터 시작 부품, 잠금된 부품과 어느 캐릭터든 장착 중인 부품은 분해하지 않는다. 잠금, 제작·분해, 재화와 제작법은 기존 진행 저장에 반영한다. 기존 상점품과 시험 부품의 개별 ID 및 다른 사본을 보존하며 분해한 상점품은 다시 구입할 수 있다.
- 마을 공방·장비 상점과 출격 준비의 보유 재화를 빈 오른쪽 위로 옮겼다. 금액 영역을 넓히고 긴 금액은 크기를 조절해 잘림을 방지한다. 제작·연구·도감 등의 공통 버튼에서 표시 가능한 기본 글자 크기를 키웠다.
- 512픽셀로 축소되던 일곱 투명 초상화와 결정·골드 이미지는 원본 해상도로 가져온다. 초상화 축소 시 밉맵과 선명도 보정을 사용해 작은 버튼의 계단 현상을 줄인다.

## 검증

- Unity 6000.3.21f1 배치 PlayMode 163개가 검증 사본과 `D:\Project-G`에서 각각 통과했고 실패·건너뜀은 0개다.
- 다섯 등급의 제작 비용과 절반 반환, 강화비 미반환, 재화 부족, 개별 잠금·장착·시작 부품 보호, 이전 시험 부품의 개별 분해와 상점품 재구입, 저장 재실행을 시험했다. 마을 공방의 실제 제작·확인·잠금·분해 버튼과 여러 페이지의 사본 선택을 확인했다.
- 실제 씬에서 재화의 오른쪽 위 위치와 아이콘·텍스트의 겹침 방지, 두 아이콘과 일곱 초상화의 원본 해상도·필터를 확인했다. 공방·상점·제작 화면은 1024×576 화면 밖 렌더를 확인했다. [공방](../screenshots/3d-day-59-forge-offscreen.png) · [상점](../screenshots/3d-day-59-market-offscreen.png) · [제작](../screenshots/3d-day-59-craft-offscreen.png)
