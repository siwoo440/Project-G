# 16일차 : 전체 파일 점검과 반복 처리 정리

---
## 완료한 작업

- Git 추적 파일 409개의 읽기 가능 여부와 완전 중복을 확인하고 JSON·asmdef 형식을 검사했다. PNG 26개의 디코딩과 Unity 메타데이터 짝·GUID 중복을 확인했다.
- 리소스 동적 경로, 시험용 객체와 Unity 생명주기 함수를 점검했다. 사용 여부가 불확실한 파일은 삭제하지 않았다.
- 전투 측정기의 스냅샷 저장소를 재사용해 매 프레임의 객체 생성 경로를 줄였다. 외부에 전달하는 기록은 독립 사본으로 유지한다.
- 적탄이 같은 풀의 카메라 구성 요소를 반복 조회하지 않도록 참조를 재사용한다. 카메라가 없거나 파괴되면 다시 조회한다.

---
## 확인한 테스트

- Unity 6000.3.21f1 비대화형 배치 모드에서 EditMode 311건과 PlayMode 44건이 통과했다.
- 측정 기록의 독립 사본, 잘못된 입력 거부, 전체 필드 갱신과 재출격 초기화를 확인했다.
- 카메라 추가·삭제·교체·비활성화와 크기 변경, 적탄 풀 재사용을 확인했다.
- 추적 파일의 완전한 바이트 중복, 메타데이터 짝 누락 및 GUID 중복은 발견하지 못했다. 사용자 ShaderGraph 설정의 기존 변경은 보존했다.

---
## 남은 작업

- 정적 GUID 대조에서 확인되지 않은 7개는 Unity 패키지 또는 내장 참조 여부를 확인해야 하며, 이를 오류로 단정하거나 삭제하지 않았다.
- 실제 GPU 성능, FPS 및 관리 메모리 절감량은 측정하지 못했다. Editor가 지원하지 않는 GC 모드 계측 시험은 제거했고 최종 전체 시험을 다시 통과했다.
- 아군 탄환의 반복 표적 탐색·정렬과 생성·파괴는 후속 프로파일링 대상이다. 실제 병목이라고 단정하지 않았다.
