# 17일차 : 저장 실패와 강제 종료 복구 검증

---
## 완료한 작업

- 저장은 반영됐지만 실패 응답이나 예외가 발생한 경우, 저장 원문을 다시 읽어 이번 목표 원문과 정확히 일치할 때만 저장 성공으로 확정한다.
- 확인 원문이 다르거나 읽을 수 없으면 기존 메모리와 원래 오류를 보존하고 다른 내용을 덮어쓰지 않는다.
- 별도 Unity 프로젝트와 고유 임시 저장 경로에서 저장 완료 후 시험 프로세스를 강제 종료하고 복구하는 재현 도구를 추가했다.

---
## 확인한 테스트

- Unity 6000.3.21f1 비대화형 배치 모드에서 EditMode 319건과 PlayMode 44건이 통과했다.
- 격리된 파일 쓰기 잠금 실패·해제·재시도·재시작 및 정산 중복 방지와, 저장 응답 누락·예외·읽기 실패·다른 원문 보호를 확인했다.
- 독립 Unity 시험 프로세스가 출격 시작을 저장하고 표식을 동기 기록한 뒤 해당 프로세스만 강제 종료했다. 새 프로세스에서 미정산 실패 복구·중복 방지·다음 출격 정산, 또 다른 프로세스에서 파일 재로드와 보상 보존을 확인했다.
- 복구 시험의 최종 결과는 속사 숙련도 10, 저격 숙련도 20, 공통 재료 9, 영수증 2개, 진행 중 출격 없음이었다. 보상 수치는 현재 기획의 시험값이다.
- 재현은 저장소의 `tools/day17-recovery-probe.py`를 Unity 6000.3.21f1이 설치된 Windows에서 실행한다. 도구는 운영체제 임시 폴더에 별도 프로젝트와 저장 경로를 만든다.

---
## 남은 작업

- 실제 게임 GUI 플레이 또는 독립 실행 빌드에서 강제 종료를 확인하지 않았다. 시험 종료 시점은 저장과 표식 완료 후이므로 파일 교체 도중 종료나 전원 차단의 복구는 검증하지 않았다.
- 영구 해금 상품과 세부 규격은 결정 전이며 실제 해금 흐름의 전체 복구는 검증하지 않았다.
