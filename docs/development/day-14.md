# 14일차 : 전투 판정과 화면 연출 보완

---
## 완료한 작업

- 돌진 적이 현재 프레임의 플레이어 이동 이후 접촉을 판정하도록 수정했다. 같은 프레임에 돌진과 적탄이 접촉하면 기존의 돌진 우선순위를 유지한다.
- 화면 안에서 사격형 적과 보스의 탄막 발사 전 경고 이미지를 제거했다. 발사 시간은 유지하고, 탄막과 별개인 돌진 경고와 보스 약점 표시는 유지했다.
- 시험 발사기의 사전 표시를 제거하고 발사 위치와 시간 간격을 유지했다.
- 저격형 고유 스킬용 시험 이미지를 생성해 고유 스킬 칸에 연결했다. 전투 정보와 실패 안내가 서로 다른 줄을 사용하도록 조정했다.
- 하늘섬 배경을 위에서 아래로 이동하도록 구현했다. 이미지를 뒤집지 않고 반복 경계를 혼합하며, 일시정지와 재출격 초기화를 연결했다. 이동 속도는 시험값이다.

---
## 확인한 테스트

- Unity 6000.3.21f1 비대화형 배치 모드에서 EditMode 297건과 PlayMode 42건이 통과했다.
- 이전 이동 궤적 재사용으로 인한 오피격, 현재 이동 접촉 누락, 같은 프레임의 돌진·적탄 우선순위를 실제 Unity 프레임 회귀 시험으로 확인했다.
- 사격형 적과 보스의 경고 제거, 보스 약점·돌진 경고 유지, 시험 발사기의 발사 위치와 간격을 확인했다.
- 캐릭터별 고유 스킬 이미지 선택, 화면 높이에 따른 정보 줄 간격, 배경의 이동·정지·재출격 초기화와 셰이더 가져오기를 확인했다.

---
## 남은 작업

- 사람의 실제 조작감과 회피·공격·스킬·보스 차별성, 탄막과 HUD 가독성은 확인하지 못했다.
- 실제 GPU에서 배경의 이동 방향·이음새·색상과 독립 실행 빌드의 셰이더 포함 여부는 확인하지 못했다. 그래픽 장치를 사용하지 않은 배치 시험은 시각 확인이 아니다.
- 화면 밖 탄환의 즉시 충돌 방지와 위험 구역의 공정성은 실제 플레이 검증이 필요하다.

---
## 다음 일차

- 15일차에는 강화 아이템과 카드 공통 상한의 시험값을 검토하고 자동 확인 가능한 드롭·획득 규칙을 검증한다. 보스 드롭, 획득 반경·유지 시간과 보호막 소모 순서는 미정 또는 시험값으로 유지한다.
