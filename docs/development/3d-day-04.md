# 3D 4일차 적탄 피격과 그레이즈

---
## 구현

기체와 적탄이 한 프레임 동안 이동한 상대 경로를 검사해 고속 탄환도 판정한다. 시험 반경은 피격 0.38, 그레이즈 0.90 월드 단위다. 적탄의 반경을 합산한다. 근접 구간을 피격 없이 지난 탄만 그레이즈를 한 번 올린다. 피격 후 1초 동안 보호한다.

체력이 0이 되면 비행과 사격이 중단된다. T로 적탄 연습을 전환하고 R로 재시작한다. 체력·그레이즈·연습 상태는 3일차에 제작한 조작 안내판에 표시한다.

---
## 검증

- Unity Play Mode 10개 통과. 한 프레임을 건너는 고속 적탄, 무적 구간, 스친 뒤 명중한 탄의 그레이즈 취소, 실패와 R 재시작을 검증했다.
- Windows 1920×1080 시험 빌드에서 적탄 판정 후 HP 80, GRAZE 1을 확인하고 화면을 캡처했다.
- 직접 조작감, 다른 PC에서의 성능과 많은 탄환의 처리량은 검증 전이다. 5일차에는 입체 탄막 패턴과 적탄 재사용을 다룬다.
