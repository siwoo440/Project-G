# 3D 49일차: 제작 마법의 전투 강화

---
## 구현

- 레벨업 선택에 현재 출격에 편성한 제작 마법의 유효한 수치 강화 후보를 추가했다. 같은 구성 ID를 두 칸에 장착해도 후보를 중복 제시하지 않고 강화 단계와 쿨타임을 공유한다.
- 구성마다 총 `+3`까지 피해, 쿨타임, 마력, 다중 발사체 수, 기존 관통 대상, 범위와 유지시간을 강화한다. 피해가 없는 결계의 피해 강화 등 효과가 없는 선택은 제외한다. 추가 탄환 24발, 관통 5명과 결계 유지 6초 등 기존 상한을 유지한다.
- 강화된 소수점 마력 비용은 실제 보유량과 비교해 소비한다. 피해와 범위, 발사체 수, 결계 수명은 시전할 때 확정하므로 이후 강화가 이미 진행 중인 탄환·결계·쿨타임을 바꾸지 않는다.
- 전투 카드에 강화 단계, 구성 비용, 실제 마력 비용과 대기시간, 마력 부족 또는 편성 한도 초과 상태를 표시한다. 일반 출격의 재시작에서는 임시 강화와 쿨타임을 초기화한다.
- 영구 제작 마법의 JSON 저장 형식에 임시 강화는 추가하지 않았다. 기존 저장과 48일차의 빈 칸·중복 편성 복원 경로를 유지한다.

---
## 검증

- Unity 6000.3.21f1 배치 PlayMode 106개 통과, 실패·건너뜀 0개. 기존 저장·전투·결과·정산·재출격과 UI 회귀를 포함한다.
- 실제 레벨업 후보 추첨과 선택, 중복 슬롯의 후보 중복 제거와 강화 공유, `+3` 상한 및 상한 이후 후보 제외를 확인했다.
- 마력 14.20은 비용 14.25의 시전을 거절하고 14.25에서는 정확히 소모했다. 이미 발사한 탄환과 시작된 쿨타임은 강화 후에도 기존 수치를 유지했다.
- 가시 산탄의 8→9발, 관통 강화 5명 상한, 정화 결계의 기존 효과 유지와 다음 시전의 반경·유지시간 증가를 확인했다. 강화한 화염 직격 피해와 유리 상성을 실제 마물 체력에 적용했다.
- 전투 카드의 양쪽 강화 단계, 공유 대기시간, 구성 비용, 마력 부족과 편성 한도 초과 표시를 확인했다.

---
## 미검증과 다음 작업

- Windows 실제 플레이어 화면의 카드 가독성과 조작 체감, 다른 PC 수동 시험은 실행하지 않았다. 카드의 내용과 활성 상태는 Unity 배치 시험으로 확인했다.
- 현재 탐험 시제품은 경험치와 레벨업 선택을 비활성화한다. 탐험에서의 제작 마법 강화 획득·구간 간 보존은 탐험 정식화 때 구현과 검증이 필요하다.
- 마법 공격력이 실제 피해에 미치는 구체적인 산식은 확인하지 못했다. 구성 비용 한도는 현재 장비 보정을 사용하며, 피해 산식은 기획 확인 후 후속 종합 실측에 반영한다.
- 50일차에는 9개 구성 분류의 범용 제작·발사·판정 기반과 발사체 이중 상한을 확장하고 초기 4종 및 적탄 판정을 회귀 검증한다.
