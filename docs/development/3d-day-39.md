# 3D 39일차 | 음악·전투 효과음과 음량

---
## 구현

- 타이틀, 마을·출격 준비, 일반 전투·훈련, 보스에 처음 작동을 확인할 자체 제작 반복 음악을 적용했다. 중간·최종 보스에서 공용곡을 사용한다. 결과는 실제 출격 결과에 맞춰 완료곡 또는 실패곡을 한 번 재생한다.
- 사격·피격·그레이즈·격파·일반 스킬·필살기·마법 카드·획득·레벨업·UI 확인·복귀용 효과음 11개를 실제 행동에 연결했다. 자동탄과 같은 효과를 연달아 재생할 때 재생 간격을 제한한다.
- 씬의 `FlightAudio/Music`, `CombatSfx`, `InterfaceSfx`에서 소스와 음량 또는 클립을 수정한다. 정지 시 전투와 배경을 멈추고 UI는 여전히 반응한다. 배경 음악은 씬이나 보스가 바뀔 때 하나만 재생된다.
- 제작 음원의 프롬프트, 용도, 길이, 출력 형식과 교체 파일명은 [기획서 13.7 사운드·음성](https://docs.google.com/document/d/11SYgjADf-6TG3s7-TG01_Ue1nwgq3DP6-zUa63HLyig/edit?tab=t.p64gk563fhsh)에 기록한다.

---
## 검증

- 원본 PCM WAV 17개의 실제 샘플과 최대 진폭을 검사했다. 전부 32kHz 16비트 스테레오이며 빈 파일이나 클리핑이 없다.
- Unity 6000.3.21f1 PlayMode 테스트 84개 통과. 기본곡의 씬별 연결과 단일 재생, 보스 및 결과 분기, 정지와 음량 저장을 확인했다.
- Windows 1920×1080 자동 실행에서 제목·마을·실전·중간 보스·완료·실패 음악의 PCM, 자동 사격과 정지 메뉴 버튼음의 PCM을 확인했다. 정지 중 전투 파형이 멈추고 재개되는 것과 마스터 61% 저장 후 복원도 검증했다. 결과 두 경우는 통제된 보고서를 사용했다.
- 사람의 청취와 최종 음원 교체, 캐릭터 음성 제작은 후속이다.
