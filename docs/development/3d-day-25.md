# 3D 25일차 출격 결과와 재출격

---
## 결과 화면

최종 보스 격파와 피격 실패를 `CombatHUD/SortieEnd`에 연결했다. 결과 확인 버튼 또는 Enter를 누르면 별도 씬 `FlightSortieResult`가 열린다. 전투·전체 시간, 점수, 격파 수, 그레이즈, 도달 레벨은 실제 전투가 끝난 순간에 확정한다. 종료 확인과 결과 버튼, 텍스트는 하이러키에서 편집할 수 있다.

같은 조합으로 재출격하면 기존 조종사와 저장한 장비·마법을 새 전투에 적용한다. 체력, 전투 기록, 카드 강화와 일시정지 상태를 초기화한다. 메인 화면 버튼으로 타이틀에 복귀한다.

---
## 검증

Unity 6000.3.21f1의 Play Mode 테스트 69개로 최종 보스 격파·피격 실패·결과 표시·재출격·타이틀 복귀를 확인했다. 전체 시간이 전투 시간보다 작아질 수 없도록 시간 집계를 추가 검증했다.

독립 Windows 빌드에서 1920×1080 아리아 클리어와 메인 복귀, 1024×576 리안 실패와 같은 조합 재출격을 확인했다. 클리어는 가속한 전투에서 실제 보스의 피해 처리로 재현했다. [클리어 결과](../screenshots/3d-day-25-clear.png) · [1024×576 실패 결과](../screenshots/3d-day-25-failed-1024.png)

수동 완주는 28일차 검증 범위다. 26일차에는 영구 정산과 강제 종료 후 복구를 연결한다.
