# 3D 36일차 | 이리스 확산 파동과 창공의 공명

## 구현

- 이리스의 기획서 스탠딩, 장비·공용기, 전용 Q·R 아이콘을 출격에 연결했다. 이제 마을의 장비 시설과 출격 준비에서 조종사 일곱 명을 선택할 수 있다.
- 실제 체력을 깎은 서로 다른 마물마다 2초 동안 공명 범위가 10%씩 오르며 기본 상한은 30%다. 같은 대상을 다시 맞히면 해당 대상의 지속 시간만 갱신한다.
- Q 확산 파동은 전방 3D 원뿔에 들어오는 적에게 65 피해를 준다. R 창공의 공명은 직접 파동 피해 140을 주고 실제로 맞힌 가장 가까운 적을 시작점으로 서로 다른 새 대상에게 최대 두 번 이어지며 각각 피해 30을 준다. 월드 지형은 직접 타격과 연쇄를 막는다.
- Q의 마력 25·대기 8초, R의 에너지 100, 기본 파동 거리 10m·16m와 연쇄 거리 4.2m를 사용한다. 거리는 3D 시험값이다.
- 연쇄 공명 1은 공명 상한을 40%로 올리고 집중 파동 1은 집중 자동탄의 폭을 20% 좁혀 피해를 20% 높인다.
- 실전과 연습 씬의 `AriaPilot/IrisWaveFront`, `AriaPilot/IrisChainLinks`에서 파동과 연쇄 효과를 직접 편집할 수 있다.

## 검증

- Unity 6000.3.21f1 PlayMode 81개 통과. Q의 고도 범위, 동일 적의 중복 스택 방지, 2초 만료, R의 다른 두 적 연쇄와 단일 중간 보스 중복 피해 제한을 확인했다.
- Windows 1920×1080 자동 실행에서 이리스의 실제 출격, Q·R과 두 고도의 적중, 30% 공명 HUD, 결과 스탠딩 및 재출격을 확인했다. 게임을 직접 조작한 최종 밸런스는 후속 검증이다.
