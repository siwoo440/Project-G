# 3D 56일차: 제작 연구·도감과 자유 비행 연결

---
## 구현한 범위

- 출격 준비의 제작 화면과 마을 강화 공방에서 아홉 분류의 연구 진행률과 선행 조건을 확인하고 연구·상점·보상 선택을 확정한다. 연구가 잠기거나 미지원인 기존 조합은 저장을 보존하며 전투 편성에서는 제외한다.
- 단일 마법 저장을 여러 도감 항목으로 호환 복원한다. 저장·검색·속성 및 비용 필터·복제·이름 변경과 삭제 확인을 제공하고, 현재 편성에서 참조 중인 구성은 직접 편성을 해제하기 전까지 삭제하지 않는다.
- 현재 캐릭터와 저장 빗자루로 편집 중인 마법을 독립 자유 훈련에서 사용한다. 제작 화면의 중앙 미리보기와 전체 화면은 같은 비행 세션을 공유하고, 포커스 획득 클릭은 발사하지 않는다. 연습 표적 거리·체력·마력 표시와 초기화를 실제 비행 연습에 연결한다.
- 이동형 마법에 표준·고속·장거리의 확정 탄속·사거리 비율과 빗자루 보정을 적용한다. 같은 구성과 성능 프리셋은 쿨타임과 임시 강화를 공유하고 서로 다른 프리셋은 구분한다.
- 마법 한도가 감소하면 낮은 유지 우선순위와 최근 편성 순서에 따라 자동 해제한다. 자동 해제한 슬롯의 유지 효과를 종료하되 독립 탄환은 유지하고, 한도 회복 시 기존 정상 편성을 해제하지 않는 범위에서 원래 슬롯·강화·쿨타임을 복구한다.
- 실제 전투가 시작된 뒤 정지 메뉴의 제작·편성 변경을 차단한다. 연구 화면 설명과 제작 버튼의 겹침을 고치고 오프스크린 렌더를 확인했다.

## 실행한 검증

- Unity 6000.3.21f1 배치 PlayMode 전체 153개가 검증 사본과 `D:\Project-G`에서 각각 통과했고 실패·건너뜀은 0개다. 저장·전투·정산·재출격과 기존 중단 복구 시험을 포함한다.
- 연구 구매 확인·취소·상점·무료 선택권과 선행 노드 이동, 이전 잠금 편성 보존, 도감 검색·복제·이름 변경·삭제 참조 보호 및 구형 단일 저장 이관을 시험했다.
- 실제 비행 미리보기의 입력 분리, 첫 클릭 발사 차단, 실제 표적 명중, 총구 기준 표적 거리, 표적·마력 표시, 초기화, 전체 화면 전환, 편집 조합 변경, 보상 격리 및 로드 중 취소를 시험했다.
- 우선순위 자동 해제·복구, 직접 해제 제외, 강화·쿨타임 보존, 유지 결계 종료와 이미 발사된 탄환 보존을 시험했다. 이동형 프리셋과 장비 탄속·사거리, 회류 원반과 씨앗 자탄을 확인했다.
- 1280×720 오프스크린 렌더로 제작·연구·도감·내장 비행 화면을 확인했다. 이는 실제 모니터에서의 수동 플레이 검증이 아니다. [비행 화면](../screenshots/3d-day-56-preview-offscreen.png) · [연구 화면](../screenshots/3d-day-56-research-offscreen.png)

## 남은 작업

- 56일차는 부분 구현이다. 9개 구성의 아이콘 선택·검색 화면과 시각적 연구 연결도, 아군 연출 강도 50·100·125% 설정은 아직 구현하지 않았다.
- 내장 연습은 기존 시험 항로와 중립 표적을 사용한다. 기획서의 120×80×120m 경계, 이동·다수·보스 표적과 적탄 시험 조건, 상세 실측·비교 패널은 미구현이다.
- 도감은 현재 편성의 동일 구성 참조를 보호한다. 개별 복제본의 슬롯 참조와 아직 구현하지 않은 빗자루 프리셋 참조·삭제 확인은 후속 작업이다.
- 정식 리소스, 실제 Windows 화면 및 조작, 1920×1080·1024×576 검증, 다른 PC와 Steam 실연동은 미실행이다. 55일차의 일반 적 30마리·정예 보상도 현재 웨이브에서 자연 플레이로 검증하지 못했다.
- 57일차는 기획서 14.10~14.11의 10개 세트 80종과 시작 부품 56종, 5등급 능력치 및 기존 저장 호환을 다룬다. 56일차의 미완료 항목은 후속 일정에서 계속 추적한다.
