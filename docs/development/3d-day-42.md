# 3D 42일차 | 보스 러시와 조종사별 최고 기록

---
## 시제품 규칙

- 출격 준비의 **보스 러시** 버튼 또는 **F5**로 들어간다. 현재 캐릭터의 빗자루와 마법 편성을 사용한다.
- 첫 2.5초 뒤 중간 보스를 만나고, 격파 2.6초 뒤 최종 보스가 등장한다. 중간 보스의 잔류 탄막을 회수하고 체력과 마력을 최대로 회복한다. 필살기 충전과 스킬 쿨타임을 유지한다.
- 최종 보스는 기존 3페이즈를 사용한다. 두 보스를 모두 쓰러뜨리면 일시정지를 제외한 전투 시간을 백분의 일 초 단위로 조종사별 기록에 저장한다. 실패 후 같은 조합으로 다시 도전할 수 있다.
- 영구 재화, 숙련도, 경험치와 강화 아이템은 지급하지 않는다. 본편의 이어서하기와 첫 사건 진행을 보존한다.
- 하이러키에서 준비 버튼은 `SortieBriefing/Ready/BossRush`, 보스 배열은 외곽 항로의 `EnemyEncounter`에서 편집한다.

---
## 검증

- Unity 6000.3.21f1 PlayMode 88개 통과. 중간 보스 격파 후 체력·마력 회복, 다음 보스 출현, 세 페이즈, 최고 시간 보존을 검증했다.
- Windows 1920×1080과 1024×768 자동 입력으로 F5·실제 전투 진입·통제 피해·정산·같은 모드 재도전을 확인했다. 기존 본편 재화, 숙련도와 이어서하기는 그대로였다. 자동 검사 시간은 전투 밸런스 기록에 포함하지 않는다.
