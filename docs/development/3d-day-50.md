# 3D 50일차: 제작 마법 발사와 상태 기반

---
## 구현

- 사용자 확정에 따라 `기준 피해 × 시전 시점 마법 공격력 ÷ 100`을 직격과 폭발 피해에 적용한다. 출격 중 강화와 적의 속성 상성도 적용하며, 발사 후 공격력이 달라져도 이미 발사한 탄환은 당시 피해를 유지한다.
- 9개 구성 분류의 기존 비용·ID·호환성 검증을 유지하고, 8가지 생성 기준의 실제 좌표를 구분하는 공통 경로를 추가했다. 현재 구현된 전방 발사와 주변 결계에 연결했으며, 좌표가 없거나 유효하지 않으면 생성하지 않는다. 카메라 조준은 실제 생성 위치를 기준으로 보정한다.
- 한 시전의 최초 24개·누적 96개와 플레이어의 초당 40개·동시 128개 상한을 함께 검사한다. 발사체와 결계가 같은 플레이어 한도를 공유한다. 실패한 시전은 일부만 생성하거나 마력을 소비하지 않으며, 카드에 생성 한도 상태를 표시한다.
- 같은 시전의 발사체에 공통 생성 기록을 부여하고 후속 생성 예약에 재사용할 수 있도록 했다. 재출격 후에는 이전 시전 기록을 사용할 수 없다.
- 공통 대상 상태 처리에 중첩별 독립 만료, 최소 0.5초 간격, 최대 6초 유지, 최대 3중첩 및 재적용 거절을 추가했다. 기존 수압 파동의 실제 넉백은 공통 상태 처리로 연결했다. 연습 표적의 시간은 정지된 실전과 분리한다.
- 사용자가 정한 범위에 따라 수치와 판정이 모두 준비된 기획 마법만 시전한다. 기존에 저장된 미지원 조합의 ID와 편성은 보존하고 카드에 미지원 상태를 표시한다.

---
## 검증

- Unity 6000.3.21f1 배치 PlayMode 114개 통과, 실패·건너뜀 0개. 초기 마법과 전투, 적탄, 저장·정산·재출격, UI 회귀를 포함한다.
- 생성 위치 8종의 명시된 좌표와 미지정·잘못된 좌표 거절을 확인했다. 실전에서는 기존 전방 발사와 주변 결계를 확인했다.
- 최초 24, 시전 누적 96, 초당 40, 동시 128 경계와 한도 초과를 시험했다. 실제 발사체와 결계에서 초당·동시 한도와 마력 무소모를 확인했다. 분열체의 실제 생성은 52일차에 연결한다.
- 실제 마물에서 화상 3중첩의 독립 만료와 지속 피해, 중복 불가 저주, 정지·연습 시간 분리 및 회수 후 상태 초기화를 시험했다. 화상과 저주를 해당 15종 마법에 연결하는 작업은 각각 51·53일차에 남았다.
- 공격력 120·80에서 기준 피해 35가 각각 42·28이 되는 것과 발사 후 공격력 변경 시 기존 피해 보존을 확인했다. 실제 마물의 폭발 피해와 속성 상성도 확인했다.
- 미지원 구성의 기존 ID가 다른 슬롯 저장과 재진입 이후에도 보존되고, 실제 시전과 추측한 마력 표시는 차단되는 것을 확인했다.

## 미검증과 다음 작업

- 현재 실제 시전 가능한 기획 마법은 파이어 볼트·수압 파동·가시 산탄·정화 결계와 기존 발사기가 지원한 홀리 샤워다. 15종의 나머지 효과와 홀리 샤워의 본격 실측은 51~53일차에 진행한다.
- 8개 위치 중 지정 좌표·비행 경로·목표물·소환체·기존 탄환·후방의 실제 콘텐츠별 좌표 산출과 발사는 이후 해당 마법을 구현할 때 연결한다. 단위 시험에서 제공된 좌표를 구분한 사실을 실전 검증으로 간주하지 않는다.
- Windows 실제 플레이어의 화면·조작, 다른 PC, Steam 실연동, 정예·보스 특수탄의 전체 분류는 미검증이다.
- 51일차에는 플레임 스파이럴·급류 관통탄·회류 고리·홀리 샤워의 실제 탄환, 순차 발사·관통·회귀 및 대상별 중복 제한을 구현하고 실측한다.
