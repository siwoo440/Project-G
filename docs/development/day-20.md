# 20일차 : 강화 아이템·과제 연결과 전투 화면 보완

---
## 완료한 작업

- 중간 보스 처치 시 적용 가능한 강화 아이템 후보가 있으면 하나를 확정 드롭한다. 일반 적 드롭 확률은 10% 시험값이며 최종 보스는 강화 아이템을 드롭하지 않는다. 유효한 후보가 없으면 중간 보스도 드롭하지 않는다.
- 시간제 보호막과 강화 아이템 보호막이 함께 있을 때 시간제 보호막을 먼저 사용하도록 했다. 강화 아이템 보호막은 남은 방어 횟수를 관리한다.
- 아리아의 첫 고유 과제에 한 출격의 유효한 기본·집중 공격 50회 적중을 연결했다. 실패와 클리어 결과에서 출격 정산과 과제 보상을 함께 저장하고 중복 지급을 방지한다.
- 일반 적과 중간·최종 보스 몸체 아래에 실제 피해 시 체력바를 표시한다. 추가 피격 시 표시 시간을 갱신하며, 피격 후 2초 표시는 시험값이다. 처치·비활성화·재사용, 일시정지와 플레이어 사망 시 표시 상태를 처리한다.
- 조준형·확산형·돌진형·중간 보스·최종 보스의 기존 단일 이미지를 종류별로 부유·회전·맥동시킨다. 몸체 이미지만 움직이고 적 기준 위치, 피해 판정, 발사 위치, 약점 및 체력바 기준은 유지한다. 별도 프레임이나 날개 애니메이션은 제작하지 않았다.
- 기획서의 아리아·리안 스탠딩 원본 이미지를 알파를 보존해 출격 준비 화면에 적용하고 키보드 선택과 화면 안내를 개선했다. 캐릭터 전투 스프라이트는 그대로 유지했다.
- 키 설정의 일부가 손상되거나 누락돼도 정상 저장된 다른 키를 먼저 보존한다. 화면 설정 저장에 실패하면 저장 상태 확인을 안내하고, 이전 설정 복구 요청에도 실패한 경우 이를 별도로 안내한다.

## 확인한 테스트

- Unity 6000.3.21f1 비대화형 배치 모드에서 전체 EditMode 408건과 PlayMode 47건이 통과했다.
- 강화 아이템 유효 후보·드롭 출처와 확률 경계, 보호막 우선순위, 아리아 과제의 적중·정산·중복 지급 및 저장 실패를 자동 시험했다.
- 적 5종의 체력 표시·재사용과 몸체 변형, 판정 독립, 일시정지·플레이어 사망, 중간·최종 보스의 체력바와 몸체 비겹침을 자동 시험했다.
- 출격 준비 화면의 원본 이미지 연결·선택과 키보드 조작, 손상된 키 설정 복원 및 화면 설정 저장·복구 실패 안내를 자동 시험했다.
- 사용자 화면을 전환하지 않는 별도 격리 실행에서 아리아·리안 준비 화면, 960×540 화면, 긴 정보 스크롤과 적 체력바를 GPU로 캡처·확인했다. 같은 적 몸체의 시간에 따른 위치·회전·크기 변화도 기록했다. 실제 게임 화면 원본 5장을 README에 반영했다.

## 남은 작업과 미정 사항

- GPU 캡처는 자동으로 화면을 전환하고 시험 피해를 적용한 결과다. 사람이 직접 조작한 플레이의 가독성·조작감과 움직임 품질 평가는 확인하지 않았다.
- 체력바 2초, 일반 적 드롭 확률 10%, 각 적의 움직임 폭과 속도는 시험값으로 실제 플레이에서 검증·조정해야 한다. 적 자체 사망 직후 몸체 움직임 정지는 별도 직접 시험이 필요하다.
- 리안의 첫 과제 상세 공격 범주는 미정이며 실제 과제 연결은 구현하지 않았다. 강제 종료된 출격의 과제 복구도 구현하지 않았다.
- 화면 설정의 PlayerPrefs 여러 값 쓰기는 원자적이지 않아 저장 실패 시 일부 값이 남을 수 있다. 실패 안내는 이 불확실성을 표시한다.
