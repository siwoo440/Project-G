# 3D 64일차: 확정 성장·과제 검증

---
## 구현과 확인

- 기존 일곱 조종사의 1단계 전용 카드와 조종사별 장비·성장·결과 격리를 확인했다. 확정된 아리아 추격·확산 2단계와 리안 약점 사냥 2단계의 선행·영구 해금 및 효과를 기존 구현에서 확인했다.
- 아리아의 기본·집중탄이 최종 보스의 페이즈 전환 무적에 닿았을 때 속사 보너스가 증가하던 문제를 수정했다. 실제 적의 체력이 감소한 유효 적중만 누적하고 기존 연습 표적은 유지한다.
- 아리아 첫 과제의 49·50회, 리안 몸통 적중 제외와 약점 9·10회, 새 출격 초기화 및 과제 중복 정산·저장 복원을 시험했다.

---
## 검증

- Unity 6000.3.21f1 배치 PlayMode 194개가 검증 사본과 `D:\Project-G`에서 각각 통과했다. 실패·건너뜀은 0개다.
- 최종 보스 전환 무적에 대한 추가 시험은 수정 전 실패를 확인한 뒤 수정 후 통과했다. 정상 적중의 속사 누적도 확인했다.
- 확정 과제 경계 시험은 실제 전용 적중 콜백을 직접 호출한 자동 시험이다. 50번·10번의 실제 플레이와 모든 물리 충돌 조합을 수동 실연한 결과는 아니다.

---
## 남은 작업

- 64일차는 확정된 범위만 진행했다. 아리아·리안 외 다섯 조종사의 첫 고유 과제 조건과 후속 노드의 영구 해금 조건·비용, 리안 관통 궤도 2의 약점 피해 합산 방식은 정해지지 않아 구현하지 않았다.
- 60일차의 미연결 장비 특수 효과와 63일차의 정식 부품 3D 모델·희귀도 외형·상세 필터를 비롯한 이전 일차의 미완료 항목이 남아 있다.
- 다음 65일차에는 강화 아이템·레벨업 카드·경제의 확정 규칙과 실제 출격을 확인한다. 다른 PC 수동 시험과 Steam 실연동은 미실행이다.
