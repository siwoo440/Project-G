# 15일차 : 강화 아이템과 카드 규칙 검증

---
## 완료한 작업

- 강화 아이템 9종의 I~V 시험 수치와 드롭 후보 규칙을 현재 기획서와 대조했다.
- 아이템 획득을 플레이어 이동 이후에 판정하고, 아이템 생성 이전의 이동은 제외했다. 만료되는 프레임에는 유지 시간 안에 해당하는 이동 구간만 획득 판정에 사용한다.
- 아이템 정보에서 획득한 아이템의 누적 수치와 카드까지 합산한 실제 전투 수치를 구분했다.
- 일반 적 처치의 드롭과 등급 가중치, 유효 등급 재가중을 고정 시드의 난수 모의 실험으로 확인했다.

---
## 확인한 테스트

- Unity 6000.3.21f1 비대화형 배치 모드에서 EditMode 308건과 PlayMode 44건이 통과했다.
- 9종 × 5등급의 실제 효과 적용, 보호막 갱신, 자석 범위와 화면 밖 제외를 확인했다.
- 생성 전 이동 제외, 현재 프레임 획득, 만료 전후 이동 구간, 일시정지와 카드·아이템 합산 상한을 확인했다.
- 고정 시드의 일반 적 처치 100,000회 모의 추첨에서 9,967회가 드롭됐으며 I~V는 각각 4,939·2,544·1,495·669·320회였다. II와 V만 유효한 별도 100,000회 추첨에서는 9,763회 드롭 중 각각 8,710·1,053회였다. 이는 난수 모의 실험이며 실제 플레이 통계가 아니다.

---
## 남은 작업

- 실제 전투의 위험 구역 아이템 회수, 획득 정보의 화면 가독성과 난이도·밸런스는 사람의 플레이로 확인하지 못했다.
- 일반 적 10%, 등급 가중치, 획득 반경 0.65, 유지 시간 20초와 효과 수치는 초기 시험값이다. 보스 드롭과 보호막 소모 순서는 미정 또는 시험 처리로 유지한다.
